五、完整流程 — y21.x0.t() 为什么返回 false
================================================================================

  y21.x0.t(fileName, duration, flag, e9Var):
    ① w0 j = j(fileName)          → F0查w0
    ② if (j == null) return false  ← 没有w0记录, 直接返回false!

  所以调用 t() 前必须先创建 w0!

七、最终完整代码 — 一行发送语音
================================================================================

  /**
   * 发送一条语音消息 (显示为语音气泡)
   * 
   * y21.x0.r() 内部做了:
   *   ① g(talker,"amr_")  → 生成文件名 + 创建w0记录
   *   ② 复制源文件到 voice2 目录
   *   ③ t(newName, duration, 1, null) → 创建e9 + 写DB
   */
  public static boolean sendVoiceMessage(ClassLoader cl,
      String talker, String sourcePath, int durationMs) {

    try {
      Class<?> y21x0 = XposedHelpers.findClass("y21.x0", cl);

      // ✅ 一行搞定 — r() 创建w0+复制文件+写DB
      String result = (String) XposedHelpers.callStaticMethod(y21x0, "r",
          talker,        // 目标会话
          sourcePath,    // 源语音文件(/sdcard/voice.amr)
          durationMs);   // 时长(毫秒)

      if (result != null) {
        XposedBridge.log("[Voice] ✅ 语音已发送: " + result);
        return true;
      }
      return false;
    } catch (Throwable t) {
      XposedBridge.log("[Voice] ❌ 发送失败: " + t.getMessage());
      return false;
    }
  }

九、w0 最小字段 (O0插入 + Q0更新)
================================================================================

  O0 插入时需要:
    w0.b  → 文件名 (必须)
    w0.c  → talker (必须)
    w0.j  → 创建时间(秒) (必须)
    w0.d  → 目录 (同文件名)
    w0.k  → 更新时间(秒)
    w0.i  → 状态=1
    w0.n  → wxid
    w0.a  → -1 (初始, O0会设置)
    w0.x  → "" (空→O0设 a|=4194304)

  Q0 更新时需要 (w0.a != -1):
    w0.h  → 时长(ms)
    w0.l  → 时长(ms)
    w0.i  → 3 (完成状态)
    w0.m  → msgId
