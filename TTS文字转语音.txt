================================================================================

  [用户] #tts 你好世界
     │
     ▼
  [ChatFooter] 编辑框输入 → 点发送
     │
     ▼
  [Hook 拦截] 检测文本前缀 #tts
     │
     ├─→ 提取内容: "你好世界"
     │
     ├─→ [Android TTS] 生成 WAV 音频
     │
     ├─→ [PCM 提取] WAV → RAW PCM 16bit 16kHz Mono
     │
     ├─→ [Silk 编码] yl.g → .amr (Silk格式)
     │
     ├─→ [构造语音消息] e9 对象，type=34(语音)
     │
     └─→ [发送语音] 调用微信消息服务发送
     │
     [取消原文本] 跳过文本发送

二章 · 关键类与方法（已核查）
================================================================================

2.1 Silk 编码器 — yl.g (MicroMsg.SilkWriter)

  构造:       yl.g(int sampleRate, int bitrate)
              ← 默认 16000, 16000

  initWriter: yl.g.b(String filePath) → boolean
              ← 打开输出文件，初始化编码器
              ← 对应 Smali: b(Ljava/lang/String;)Z

  encode:     yl.g.a(tl.h0 h0Var, int i) → int
              ← 编码 PCM 数据
              ← h0Var = PCM 数据缓冲 (h0Var.a = byte[], h0Var.b = int)
              ← 对应 Smali: a(Ltl/h0;I)I

  finish:     yl.g.d()
              ← 等待编码线程完成，关闭文件
              ← 对应 Smali: d()V

  字段:
    f: int       ← 采样率 (16000)
    g: int       ← 比特率 (16000)
    c: String    ← 输出文件路径
    k: OutputStream ← 输出流
    e: byte[]    ← PCM 缓冲区 (size = samplingRate * 20 * 2 / 1000 = 640)
    m: boolean   ← 压缩优化开关
    n: SilkWriter ← native 编码器句柄


2.2 语音消息扩展 — y21.z0 (VoiceMsgExtension)

  处理语音: y21.z0.k(com.tencent.mm.modelbase.p0) → q0
            ← 处理收到的语音消息（网络→本地）
            ← 解析 XML: .msg.voicemsg.$length / $voiceformat / $voicelength
            ← voiceformat = "4" 表示 AMR 格式

  删除语音: y21.z0.l(com.tencent.mm.modelbase.r0)


2.3 消息存储模型 — com.tencent.mm.storage.e9 (MsgInfo)

  关键方法:
    d1(String content)     ← 设置消息内容 (voicemsg XML / 文本)
    j1(String imgPath)     ← 设置媒体文件路径
    getType() → int        ← 消息类型 (1=文本, 34=语音, 3=图片, ...)
    A1(int type)           ← 设置消息类型
    N0() → String          ← 获取会话ID (talker)
    getMsgId() → long      ← 获取消息ID
    getCreateTime() → long ← 获取创建时间
    H0() → String          ← 获取用户名
    I0() → String          ← 获取内容

  语音消息 content 格式 (XML):
    <msg>
      <voicemsg
        voiceformat="4"
        length="12345"
        endflag="1"
        cancelflag="0"
        voicelength="6789"
        fromusername="wxid_xxx" />
    </msg>

  voiceformat 含义:
    0 = AMR 窄带 (8000Hz)
    4 = Silk 宽带 (16000Hz)  ← 当前微信主要使用


2.4 PCM 数据缓冲 — tl.h0

  tl.h0 是 PCM 数据载体:
    字段:
      a: byte[]  ← PCM 原始数据
      b: int     ← 有效数据长度
      c: boolean ← 是否最后一帧


2.5 文件系统工具 — w6 / z7 / r6

  w6.K(path, append) → OutputStream  ← 打开文件写入流
  z7.a(path) → z7                     ← 路径解析
  r6 构造(z7) → r6                    ← 文件信息


2.6 Messenger 服务 — com.tencent.mm.plugin.messenger.foundation

  PluginMessengerFoundation ← 消息基础服务
  v2 ← 消息分发服务

三章 · Hook 点分析
================================================================================

3.1 方案 A: Hook e9.d1 (消息内容设置) — 推荐！

  位置: com.tencent.mm.storage.e9.d1(String content)
  时机: 所有消息构造时都会调用此方法设置内容
  优点: 统一入口，文本/语音/图片都经过

  hookMethodBefore("com.tencent.mm.storage.e9", "d1", param -> {
      String content = param.args[0];
      if (content != null && content.startsWith("#tts ")) {
          // 处理 TTS
          String text = content.substring(5);
          param.setArg(0, ""); // 阻止文本发送
          processTTS(param.thisObject, text);
      }
  });


3.2 方案 B: Hook ChatFooter 发送回调

  问题: ChatFooter 方法高度混淆 (a2, a3, b1...)，定位困难
  替代: 用 DexKit 动态搜索 → findMethod().inClass(ChatFooter).name("a2")

  不推荐：因为不同微信版本混淆可能不同


3.3 方案 C: Hook 网络发送前的消息 (p0/q0)

  位置: com.tencent.mm.modelbase.p0 构造或其处理回调
  时机: 消息即将通过网络发送

  不推荐：太底层，拦截后回滚困难


3.4 ★ 推荐方案: Hook e9.X0(String content) 或 e9.d1(String)

  e9 类的 d1 方法设置消息的 XML 内容体，是所有消息类型的
  必经之路。在此处拦截 #tts 前缀是最可靠的。

四章 · TTS 转 Silk 编码方案
================================================================================

4.1 流程

  Android TTS.synthesizeToFile()
    → WAV 文件 (22050Hz/24000Hz, 16bit, Mono)
      → 提取 PCM data (跳过44字节 WAV header)
        → 重采样到 16000Hz (如果需要)
          → 送入 yl.g SilkEncoder
            → 输出 .amr 文件 (Silk格式)


4.2 Android TTS 参数

  TextToSpeech tts = new TextToSpeech(context, null);
  // 设置语言
  tts.setLanguage(Locale.CHINESE);  // 中文
  tts.setSpeechRate(1.0f);          // 正常语速
  tts.setPitch(1.0f);               // 正常音调

  // 合成到文件
  File wavFile = new File(path);
  tts.synthesizeToFile(text, null, wavFile, "tts-1");


4.3 WAV → PCM 提取

  // WAV 文件结构:
  // 0-3:   "RIFF"
  // 4-7:   文件大小-8
  // 8-15:  "WAVEfmt "
  // 16-19: 16 (fmt chunk size)
  // 20-21: 1 (PCM)
  // 22-23: 1 (Mono)
  // 24-27: 采样率
  // 28-31: 字节率
  // 32-33: 块对齐
  // 34-35: 位深度
  // 36-39: "data"
  // 40-43: 数据大小
  // 44+:   PCM 数据

  byte[] wavBytes = readFile(wavFile);
  int dataOffset = 44;  // 简单假设，实际需解析
  byte[] pcmData = Arrays.copyOfRange(wavBytes, dataOffset, wavBytes.length);


4.4 PCM 重采样 (如果需要)

  如果 TTS 输出的采样率不是 16000Hz，需要重采样。
  简单方法: 线性插值降采样。

  // Android TTS 默认输出跟设备有关，使用 AudioTrack 的采样率
  // 建议直接设置 TTS 采样率为 16000


4.5 Silk 编码

  // 创建 SilkWriter (采样率 16000, 比特率 16000)
  silkWriter = newInstance("yl.g", 16000, 16000);

  // 初始化文件
  callMethod(silkWriter, "b", amrFilePath);

  // 分帧编码 (每帧 640 字节 = 16000*20*2/1000 = 20ms)
  int frameSize = 640;
  for (int offset = 0; offset < pcmData.length; offset += frameSize) {
      int remaining = pcmData.length - offset;
      int size = Math.min(frameSize, remaining);

      byte[] frame = new byte[frameSize];
      System.arraycopy(pcmData, offset, frame, 0, size);

      // 构造 h0 对象
      h0 = newInstance("tl.h0");
      setObjectField(h0, "a", frame);
      setIntField(h0, "b", size);
      setBooleanField(h0, "c", offset + size >= pcmData.length);

      // 编码一帧
      callMethod(silkWriter, "a", h0, 0);
  }

  // 完成
  callMethod(silkWriter, "d");


4.6 语音文件路径规则

  微信语音存储在:
    /data/data/com.tencent.mm/MicroMsg/[userHash]/voice2/[talker]/[filename].amr

  talker = e9.N0()  (对方的 username / conversation id)

  filename 通常为: msg_[timestamp]_[random].amr

/*
 * TTS文字转语音 v1.0
 * 功能: 聊天窗口发送 #tts xxx → 自动转语音消息
 * 依赖: LSPilot Xposed 模块
 * 适用: 微信 (com.tencent.mm)
 */

import android.content.Context;
import android.speech.tts.TextToSpeech;
import android.speech.tts.UtteranceProgressListener;
import java.util.Locale;
import java.io.*;
import java.util.concurrent.CountDownLatch;
import java.util.concurrent.TimeUnit;

// ======================== 全局变量 ========================
tts = null;
ttsReady = false;
hostContext = null;

// ======================== TTS 初始化 ========================
log("========== TTS文字转语音插件 v1.0 ==========")
log("正在初始化 TTS 引擎...")

// 获取 Application Context
try {
    hostContext = callStaticMethod(
        findClass("com.tencent.mm.sdk.platformtools.MMApplicationContext", hostLoader),
        "getContext"
    )
    log("Context 获取成功")
} catch (e) {
    log("获取 Context 失败: " + e.getMessage())
}

// 在主线程初始化 TTS
tts = new TextToSpeech(hostContext, status -> {
    if (status == TextToSpeech.SUCCESS) {
        int result = tts.setLanguage(Locale.CHINESE);
        if (result == TextToSpeech.LANG_MISSING_DATA ||
            result == TextToSpeech.LANG_NOT_SUPPORTED) {
            log("⚠ 中文 TTS 不可用, result=" + result)
        } else {
            ttsReady = true
            log("✅ TTS 初始化成功 (中文)")
        }
    } else {
        log("❌ TTS 初始化失败, status=" + status)
    }
})

// ======================== 辅助函数 ========================

/**
 * 获取微信当前登录用户目录 (例如: 32位 MD5 hash)
 */
getAccPath() {
    try {
        // 通过 MMApplicationContext 获取账户路径
        // 通常在 /data/data/com.tencent.mm/MicroMsg/[hash]/
        acc = callStaticMethod(
            findClass("com.tencent.mm.kernel.h", hostLoader),
            "getAccPath"
        )
        return acc
    } catch (e) {
        log("获取账户路径失败: " + e.getMessage())
        return "/data/data/com.tencent.mm/MicroMsg/"
    }
}

/**
 * 获取自己的微信 wxid
 */
getMyWxId() {
    try {
        // 通过配置获取当前用户 wxid
        // 常见路径: com.tencent.mm.model.c 或 com.tencent.mm.kernel
        config = callStaticMethod(
            findClass("com.tencent.mm.kernel.h", hostLoader),
            "getUin"
        )
        return String.valueOf(config)
    } catch (e) {
        return ""
    }
}

/**
 * WAV 文件 → PCM 字节数组
 * 解析 WAV header，提取纯 PCM 数据
 */
wavToPcm(wavPath) {
    raf = new RandomAccessFile(wavPath, "r")
    try {
        // 验证 RIFF header
        riff = new byte[4]
        raf.read(riff)
        riffStr = new String(riff)
        if (!riffStr.equals("RIFF")) {
            log("❌ 无效的 WAV 文件: 缺少 RIFF header")
            return null
        }

        // 跳过文件大小 (4 bytes)
        raf.skipBytes(4)

        // 验证 WAVE header
        wave = new byte[4]
        raf.read(wave)

        // 查找 "data" chunk
        raf.seek(36)
        dataSize = 0
        while (raf.getFilePointer() < raf.length() - 8) {
            chunkId = new byte[4]
            raf.read(chunkId)
            chunkIdStr = new String(chunkId)
            chunkSize = Integer.reverseBytes(raf.readInt())
            if (chunkIdStr.equals("data")) {
                dataSize = chunkSize
                break
            }
            raf.skipBytes(chunkSize)
        }

        if (dataSize == 0) {
            log("❌ 未找到 data chunk")
            return null
        }

        // 读取 PCM 数据
        pcmData = new byte[dataSize]
        raf.read(pcmData)
        log("PCM 数据提取成功: " + dataSize + " bytes")
        return pcmData
    } finally {
        raf.close()
    }
}

/**
 * 使用 SilkWriter 将 PCM 编码为 Silk/AMR
 * @param pcmData PCM 字节数组 (16bit, 16kHz, Mono)
 * @param outPath AMR 输出路径
 * @return 编码后的文件字节数
 */
encodePcmToSilk(pcmData, outPath) {
    try {
        // 创建 SilkWriter (采样率 16000, 比特率 16000)
        silkWriter = newInstance("yl.g", 16000, 16000)

        // 初始化文件
        initResult = callMethod(silkWriter, "b", outPath)
        if (!initResult) {
            log("❌ SilkWriter 初始化失败")
            return 0
        }

        // 分帧编码
        // 帧大小 = sampleRate * 20ms * 2(bytes per sample) / 1000
        // = 16000 * 20 * 2 / 1000 = 640 bytes
        frameSize = 640
        totalFrames = (pcmData.length + frameSize - 1) / frameSize

        log("开始编码: " + pcmData.length + " bytes → " + totalFrames + " 帧")

        for (offset = 0; offset < pcmData.length; offset += frameSize) {
            remaining = pcmData.length - offset
            size = Math.min(frameSize, remaining)

            // 最后一帧如果不够 640 bytes，用 0 填充
            frame = new byte[frameSize]
            System.arraycopy(pcmData, offset, frame, 0, size)

            // 构造 tl.h0 对象
            h0Class = findClass("tl.h0", hostLoader)
            h0 = newInstance(h0Class)

            // h0.a = frame, h0.b = size, h0.c = isLastFrame
            fieldA = findField(h0Class, "a")
            fieldB = findField(h0Class, "b")
            fieldC = findField(h0Class, "c")

            fieldA.set(h0, frame)
            fieldB.setInt(h0, size)
            fieldC.setBoolean(h0, offset + size >= pcmData.length)

            // 编码这一帧
            callMethod(silkWriter, "a", h0, 0)
        }

        // 完成编码
        callMethod(silkWriter, "d")

        // 获取输出文件大小
        outFile = new File(outPath)
        fileSize = outFile.length()
        log("✅ Silk 编码完成: " + fileSize + " bytes → " + outPath)

        return fileSize
    } catch (e) {
        log("❌ Silk 编码失败: " + e.getMessage())
        // 栈追踪
        sw = new StringWriter()
        pw = new PrintWriter(sw)
        e.printStackTrace(pw)
        log(sw.toString())
        return 0
    }
}

/**
 * 计算音频时长 (毫秒)
 */
calcDuration(pcmDataLength) {
    // PCM 16bit 16kHz Mono
    // bytes → samples: samples = bytes / 2
    // samples → ms: ms = samples / 16
    return (pcmDataLength / 2) * 1000 / 16000
}

/**
 * 构建语音消息 XML content
 */
buildVoiceXml(amrFileSize, durationMs, fromUsername) {
    return "<msg>" +
           "<voicemsg " +
           "voiceformat=\"4\" " +
           "length=\"" + amrFileSize + "\" " +
           "endflag=\"1\" " +
           "cancelflag=\"0\" " +
           "voicelength=\"" + durationMs + "\" " +
           "fromusername=\"" + fromUsername + "\"" +
           "/>" +
           "</msg>"
}

/**
 * ★ 核心: TTS + Silk 编码 + 发送语音
 * @param e9Msg 消息对象 (用于获取 talker 等上下文)
 * @param text 要转换的文字
 */
processTTS(e9Msg, text) {
    if (!ttsReady) {
        log("❌ TTS 未就绪")
        return false
    }

    log("========================================")
    log("★ 开始 TTS 处理: " + text)
    log("========================================")

    try {
        // 1. 获取路径信息
        accPath = getAccPath()
        talker = callMethod(e9Msg, "N0")      // 会话ID
        myId = getMyWxId()
        timestamp = System.currentTimeMillis()

        // 2. 创建临时目录
        tmpDir = accPath + "/tts_temp/"
        new File(tmpDir).mkdirs()

        wavPath = tmpDir + "tts_" + timestamp + ".wav"
        amrPath = tmpDir + "tts_" + timestamp + ".amr"

        log("WAV 临时文件: " + wavPath)
        log("AMR 输出文件: " + amrPath)

        // 3. TTS 合成 → WAV
        wavFile = new File(wavPath)
        latch = new CountDownLatch(1)
        finalResult = new boolean[1]

        tts.setOnUtteranceProgressListener(new UtteranceProgressListener() {
            public void onStart(String utteranceId) {}
            public void onDone(String utteranceId) {
                finalResult[0] = true
                latch.countDown()
            }
            public void onError(String utteranceId) {
                finalResult[0] = false
                latch.countDown()
            }
            public void onError(String utteranceId, int errorCode) {
                finalResult[0] = false
                latch.countDown()
            }
        })

        result = tts.synthesizeToFile(text, null, wavFile, "tts-" + timestamp)
        if (result != TextToSpeech.SUCCESS) {
            log("❌ TTS 合成失败, result=" + result)
            return false
        }

        // 等待合成完成 (最多等60秒)
        latch.await(60, TimeUnit.SECONDS)
        if (!finalResult[0]) {
            log("❌ TTS 合成超时或出错")
            return false
        }

        log("✅ TTS 合成完成: " + wavFile.length() + " bytes")

        // 4. WAV → PCM
        pcmData = wavToPcm(wavPath)
        if (pcmData == null || pcmData.length == 0) {
            log("❌ PCM 提取失败")
            return false
        }

        // 5. 计算时长
        durationMs = calcDuration(pcmData.length)
        log("音频时长: " + durationMs + " ms")

        // 6. PCM → Silk/AMR
        amrSize = encodePcmToSilk(pcmData, amrPath)
        if (amrSize == 0) {
            log("❌ Silk 编码失败")
            return false
        }

        // 7. 构建语音消息 XML
        voiceXml = buildVoiceXml((int)amrSize, durationMs, myId)
        log("语音 XML: " + voiceXml)

        // 8. ★ 设置 e9 消息为语音类型
        //    类型 34 = VOICE
        callMethod(e9Msg, "A1", 34)

        //    设置语音 XML content
        callMethod(e9Msg, "d1", voiceXml)

        //    设置 AMR 文件路径
        callMethod(e9Msg, "j1", amrPath)

        // 9. 让原消息正常发送 (现在它已经是语音消息了)
        log("✅ 消息已转换为语音, 交由微信正常发送流程")
        log("========================================")

        // 清理 WAV 临时文件
        new File(wavPath).delete()

        return true

    } catch (e) {
        log("❌ TTS 处理异常: " + e.getMessage())
        sw = new StringWriter()
        pw = new PrintWriter(sw)
        e.printStackTrace(pw)
        log(sw.toString())
        return false
    }
}

// ======================== Hook 入口 ========================

/**
 * 方案: Hook e9.d1(String) — 消息内容设置
 * 拦截 #tts 前缀，自动转换文本为语音
 */
log("正在部署 Hook...")

try {
    msgClass = findClass("com.tencent.mm.storage.e9", hostLoader)

    hookMethodBefore(msgClass, "d1", param -> {
        content = param.args[0]
        if (content == null) return
        if (!(content instanceof String)) return

        str = (String) content
        if (str.startsWith("#tts ")) {
            text = str.substring(5).trim()

            if (text.isEmpty()) {
                log("⚠ #tts 后无文字内容，跳过")
                return
            }

            log("拦截到 #tts: " + text)

            // 异步处理 TTS (避免阻塞主线程)
            msg = param.thisObject
            t = new Thread(() -> {
                processTTS(msg, text)
            })
            t.setDaemon(true)
            t.start()
        }
    })

    log("✅ Hook e9.d1 部署成功")

} catch (e) {
    log("❌ Hook 部署失败: " + e.getMessage())
    log("类/方法可能不存在，请确认微信版本")
}

7.1 WAV 文件结构

  Offset  Size  内容
  ─────────────────────────────────
  0       4     "RIFF"
  4       4     文件大小-8 (Little Endian)
  8       4     "WAVE"
  12      4     "fmt "
  16      4     16 (PCM chunk size)
  20      2     1 (AudioFormat: PCM)
  22      2     1 (Mono)
  24      4     采样率 (如 16000)
  28      4     字节率 (采样率*声道数*位深度/8)
  32      2     块对齐 (声道数*位深度/8)
  34      2     位深度 (16)
  36      varies 可能还有其他 chunk
  ...     4     "data"
  ...     4     PCM数据大小
  ...     N     PCM数据


7.2 Silk 编码参数

  采样率:    16000 Hz (宽带)
  比特率:    16000 bps
  帧长:      20ms
  帧大小:    640 bytes (16000 * 0.02 * 2)
  每帧 Silk: 约 80-120 bytes (编码后)


7.3 微信语音消息类型码

  type值   含义
  ─────────────────
  1        文本消息
  3        图片消息
  34       语音消息
  43       视频消息
  47       emoji/表情
  49       链接/小程序/文件


7.4 语音 XML content 字段说明

  voicemsg 属性     含义                  示例值
  ───────────────────────────────────────────────
  voiceformat       编码格式              4 (Silk/AMR宽带)
  length            语音文件字节数         12345
  endflag           是否结束              1
  cancelflag        是否取消              0
  voicelength       语音时长(ms)          6789
  fromusername      发送者 wxid           wxid_xxx
  voiceurl          CDN 下载地址(收消息时) (空)
  aeskey            CDN 密钥(收消息时)     (空)
