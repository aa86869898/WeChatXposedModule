## 三、三种注入方案

### ★★★ 方案一: Hook u6.a() — 在菜单弹出后/显示前注入 (推荐)

```java
Class<?> u6 = XposedHelpers.findClass("com.tencent.mm.ui.tools.u6", cl);
Class<?> t4 = XposedHelpers.findClass("kc5.t4", cl);

XposedBridge.hookAllMethods(u6, "d", new XC_MethodHook() {
    @Override
    protected void beforeHookedMethod(MethodHookParam param) {
        try {
            // 获取菜单数据 g4 (字段 "i")
            Object menu = XposedHelpers.getObjectField(param.thisObject, "i");
            if (menu == null) return;

            // 获取消息信息 — 从 m (kc5.g4) 的第一项推断
            Object rawMenu = XposedHelpers.getObjectField(param.thisObject, "m");

            // ★ 注入自定义按钮
            int newId = 99999;
            XposedHelpers.callMethod(menu, "add",
                0,        // groupId
                newId,    // itemId
                999,      // order (放最下面)
                "🔥 自定义功能"
            );

            // 拦截点击回调
            Object originalCallback = XposedHelpers.getObjectField(
                param.thisObject, "g");

            // 创建代理 t4
            Object proxyCallback = java.lang.reflect.Proxy.newProxyInstance(
                cl,
                new Class[]{t4},
                new java.lang.reflect.InvocationHandler() {
                    @Override
                    public Object invoke(Object proxy, java.lang.reflect.Method method,
                            Object[] args) throws Throwable {
                        if (method.getName().equals("a") && args.length >= 1) {
                            // a(MenuItem item, int position) → void
                            android.view.MenuItem item =
                                (android.view.MenuItem) args[0];
                            if (item.getItemId() == newId) {
                                // ★ 你的自定义逻辑
                                android.util.Log.i("Injected", "点击了自定义按钮!");
                                // 获取消息对象
                                // Object msg = ...;
                                // doSomething(msg);
                                return null;
                            }
                        }
                        // 其他情况走原始回调
                        if (originalCallback != null) {
                            return method.invoke(originalCallback, args);
                        }
                        return null;
                    }
                });

            XposedHelpers.setObjectField(param.thisObject, "g", proxyCallback);
        } catch (Throwable t) {
            android.util.Log.e("MenuInject", "注入失败", t);
        }
    }
});
```

### ★★ 方案二: Hook k0.v() — 在弹窗显示后修改View

```java
Class<?> k0 = XposedHelpers.findClass(
    "com.tencent.mm.ui.widget.dialog.k0", cl);

XposedBridge.hookAllMethods(k0, "v", new XC_MethodHook() {
    @Override
    protected void afterHookedMethod(MethodHookParam param) {
        try {
            // 弹窗已显示，获取根View
            View rootView = (View) XposedHelpers.callMethod(
                param.thisObject, "c");

            if (rootView instanceof ViewGroup) {
                ViewGroup vg = (ViewGroup) rootView;

                // 找到菜单列表 (RecyclerView 或 ListView)
                View listView = findListViewRecursive(vg);

                if (listView instanceof ViewGroup) {
                    // 在列表底部添加自定义按钮
                    Button customBtn = new Button(vg.getContext());
                    customBtn.setText("🔥 自定义功能");
                    customBtn.setBackgroundColor(0xFF07C160);
                    customBtn.setTextColor(0xFFFFFFFF);
                    customBtn.setPadding(40, 20, 40, 20);
                    customBtn.setOnClickListener(v -> {
                        // ★ 你的逻辑
                        Toast.makeText(v.getContext(), "自定义按钮被点击!", 
                            Toast.LENGTH_SHORT).show();
                        // 关闭弹窗
                        XposedHelpers.callMethod(param.thisObject, "dismiss");
                    });

                    ((ViewGroup) listView).addView(customBtn,
                        new ViewGroup.LayoutParams(
                            ViewGroup.LayoutParams.MATCH_PARENT,
                            ViewGroup.LayoutParams.WRAP_CONTENT));
                }
            }
        } catch (Throwable t) {
            android.util.Log.e("MenuInject", "注入失败", t);
        }
    }

    private View findListViewRecursive(View v) {
        String cls = v.getClass().getName().toLowerCase();
        if (cls.contains("recycler") || cls.contains("list")) return v;
        if (v instanceof ViewGroup) {
            ViewGroup vg = (ViewGroup) v;
            for (int i = 0; i < vg.getChildCount(); i++) {
                View found = findListViewRecursive(vg.getChildAt(i));
                if (found != null) return found;
            }
        }
        return null;
    }
});
```

### ★★ 方案三: Hook u6.a() — 覆写适配器 onCreateMMMenu

```java
Class<?> u6 = XposedHelpers.findClass("com.tencent.mm.ui.tools.u6", cl);
Class<?> o4 = XposedHelpers.findClass("kc5.o4", cl);

XposedBridge.hookAllMethods(u6, "a", new XC_MethodHook() {
    @Override
    protected void beforeHookedMethod(MethodHookParam param) {
        try {
            Object originalAdapter = XposedHelpers.getObjectField(
                param.thisObject, "f");
            if (originalAdapter == null) return;

            Object proxy = java.lang.reflect.Proxy.newProxyInstance(
                cl, new Class[]{o4},
                new java.lang.reflect.InvocationHandler() {
                    @Override
                    public Object invoke(Object p, java.lang.reflect.Method m,
                            Object[] a) throws Throwable {
                        if (m.getName().equals("onCreateMMMenu")) {
                            // 先调原始
                            Object result = m.invoke(originalAdapter, a);
                            // 注入
                            Object menu = a[0]; // kc5.g4
                            XposedHelpers.callMethod(menu, "add",
                                0, 99999, 999, "🔥 自定义");
                            return result;
                        }
                        return m.invoke(originalAdapter, a);
                    }
                });
            XposedHelpers.setObjectField(param.thisObject, "f", proxy);
        } catch (Throwable ignored) {}
    }
});
```
