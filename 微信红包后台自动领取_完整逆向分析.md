# 微信「红包后台自动领取」完整逆向分析与独立 Xposed 模块实现方案

> 分析对象：当前 LSPilot 已加载的目标 APK（微信 `com.tencent.mm`，含 `com.tencent.mm.plugin.luckymoney` 插件 dex 与主 dex）。
> 分析方式：DexKit 定位 → view_strings / decompile / smali 取证 → 交叉验证。
> 目标：**不依赖 LSPilot / BSH** 的纯 Java Xposed（LSPosed）模块，实现 **私聊 + 群聊红包后台自动领取**、白名单、防重、到账通知。
> 本文所有类名/方法名/字段名/常量均来自反编译实证，文末附「二次核查对照表」。

## 0. 结论速览（TL;DR）

微信红包"领取"本质就是**两个普通 CGI NetScene**，和 UI 完全解耦：

| 阶段 | 类名（本版本） | CGI URI | getType() | 作用 |
|---|---|---|---|---|
| ① 预检取 token | `com.tencent.mm.plugin.luckymoney.model.n6`（`NetSceneReceiveLuckyMoney`） | `/cgi-bin/mmpay-bin/receivewxhb` | **1581** (0x62d) | 拿 `timingIdentifier`、`hbStatus`/`receiveStatus`/`hbType` |
| ② 真正领取 | `com.tencent.mm.plugin.luckymoney.model.h6`（`NetSceneOpenLuckyMoney`） | `/cgi-bin/mmpay-bin/openwxhb` | **1685** (0x695) | 领取，响应里带 **金额** |
| ③ 领取详情 | `...model.x5`（`NetSceneLuckyMoneyDetail`） | `/cgi-bin/mmpay-bin/qrydetailwxhb` | — | 谁领了/金额列表 |
| ④ 互通红包(openIM) | `...model.i6`（`NetSceneOpenLuckyMoneyUnion`） | `/cgi-bin/mmpay-bin/unionhb/openunionhb` | 5148 (0x141c) | `scene == 1005` 时走 union |

**后台领取 = 反射 new 出 n6/h6 → 丢进微信自己的网络队列 → hook 响应回调读结果**：

```
消息入库(f9.Bb) → 识别红包 → 反射 new n6 → gp0.j1.j().q().b.g(n6)
                                              ↓ 响应
                        hook n6.onGYNetEnd → 取 timingIdentifier
                                              ↓
                        反射 new h6(带上一步参数) → g(h6)
                                              ↓
                        hook h6.onGYNetEnd → 读 e1.q(= amount 分) → 发通知
```

关键结论：
- **不需要打开任何 Activity**，`LuckyMoneyNotHookReceiveUI` 只是把这些参数拼出来再调 `doSceneProgress()`；我们直接跳过 UI 层。
- 请求体由 `q5.setRequestData(Map)` 自动拼成 `k=v&k=v` 查询串并做 `URLEncoder`，**不要自己拼 HTTP**（钱包 NetScene 还要带设备/登录态/省份城市等）。
- 红包消息类型 = **`436207665`**（`0x1A000031`）；私聊/群聊**同一套** nativeUrl 与参数，只是 `sessionUserName` 不同（群=聊天厅 id，私聊=对方 wxid）。

## 3. 后台提交机制（无 UI 发请求）

### 3.1 微信的 NetScene 队列

`LuckyMoneyBaseUI.doSceneProgress(m1, boolean)` → `t4.d(m1, z)`：

### 3.2 回调链（决定我们怎么拿结果）

```
r1.g(scene)
  → q5.doScene(s, u0)      // this.d = u0   （队列回调）
  → q5.onGYNetEnd(7参)     // 解析 retcode
       ├─ retcode==0  → h6/n6.onGYNetEnd(int retcode, String retmsg, JSONObject)   ← 读金额/读 token
       └─ retcode!=0  → J(retcode, json)（h6 里是空实现）
  → finally: this.d.onSceneEnd(errType, errCode, errMsg, this)
```
实证（`q5.onGYNetEnd` 末行）：`this.d.onSceneEnd(i4, i5, string, this);`

**因此模块有两种取结果方式（推荐 A，零侵入）：**

- **A. 只读 hook**：hook `q5.onGYNetEnd`（错误/统一出口）+ `n6.onGYNetEnd(int,String,JSONObject)` + `h6.onGYNetEnd(int,String,JSONObject)`，从 `this` 读字段。完全不动微信逻辑。
- B. 抢占回调：hook `q5.doScene`，`after` 里把字段 `d` 换成自己的 `com.tencent.mm.modelbase.u0` 实现（`onSceneEnd(int,int,String,m1)`）。会顶掉微信自己对该 scene 的回调——只对我们自己 new 出来的 scene 做。

> 注意：`u0` 是接口 `com.tencent.mm.modelbase.u0`，唯一方法 `onSceneEnd(int, int, String, com.tencent.mm.modelbase.m1)`。

## 4. Hook 点设计（全部实证）

| # | Hook 目标 | 参数 | 时机 | 用途 |
|---|---|---|---|---|
| H1 | `com.tencent.mm.storage.f9.Bb` | `(e9, boolean)` | after | 新消息入库 → 识别红包 → 触发领取 |
| H2 | `com.tencent.mm.plugin.luckymoney.model.q5.onGYNetEnd` | 7 参 | after | 统一出口：errType/errCode/errMsg（风控、已领完、超时） |
| H3 | `com.tencent.mm.plugin.luckymoney.model.n6.onGYNetEnd` | `(int,String,JSONObject)` | after | 取 `P`(timingIdentifier)、`h/i/m/n`(msgType/channelId/sendId/nativeUrl) |
| H4 | `com.tencent.mm.plugin.luckymoney.model.h6.onGYNetEnd` | `(int,String,JSONObject)` | after | 取 `h`(e1) → `q`=金额、`i`=发送者昵称、`A`=receiveStatus、`f`=statusMess |
| H5（可选） | `com.tencent.mm.booter.notification.x.a(e9)` | `(e9)` | after | 兜底消息源（H1 失效的版本） |
| H6（可选） | `com.tencent.mm.plugin.luckymoney.model.x5.onGYNetEnd` | `(int,String,JSONObject)` | after | 领取详情/排行 |

**为什么 H1 选 `Bb`**：它是 `MsgInfoStorage` 唯一的主插入入口，收到的长连接消息、群漫游消息都会经过它，且在微信进程内执行（后台照样跑，不需要 UI 可见）。同类的 `Db(e9)`/`Hb(e9)` 是 `insertForBackupRecover`，不用于正常收消息。

**为什么要同时 hook H2**：`retcode != 0` 时 `q5.onGYNetEnd` 不会调用子类的 `onGYNetEnd(int,String,JSONObject)`，只走 `J(retcode,json)`（h6 里为空实现）+ `this.d.onSceneEnd(...)`。所以错误信息只能从 H2 拿。

**私聊 vs 群聊差异**（完全同一套 CGI）：

| 项 | 私聊(C2C) | 群聊(chatroom) |
|---|---|---|
| 消息类型 | 436207665 | 436207665 |
| nativeUrl | `wxpay://c2cbizmessagehandler/hongbao/receivehongbao?...` | 同左 |
| `sessionUserName` | 对方 wxid（= `msg.N0()`） | 聊天厅 id（= `msg.N0()`，以 `@chatroom` 结尾） |
| `nativeUrl` 中的 `channelid` | 一般 1 | 一般 2（**以 URL 实际值为准**，默认 1） |
| 发送者 | = talker | 需从原始 content 前缀 `"wxid:"` 取（见 5.3） |

    /* ========================= 延迟重试装钩 ========================= */
    private void ensureHooks(final int attempt) {
        WORKER.execute(new Runnable() { public void run() {
            try { Thread.sleep(attempt == 0 ? 0 : 1200L); } catch (InterruptedException ignored) {}
            boolean ok = install();
            if (!ok && attempt < 12) ensureHooks(attempt + 1);
        }});
    }

    private boolean install() {
        boolean all = true;
        all &= hookSilent(C_MSG_STORAGE, "Bb", 2);                 // H1 主
        all &= hookSilent(C_NET_BASE,    "onGYNetEnd", 7);     // H2
        all &= hookSilent(C_RECV,        "onGYNetEnd", 3);     // H3
        all &= hookSilent(C_OPEN,        "onGYNetEnd", 3);     // H4
        all &= hookSilent(C_NOTIFY,      "a", 1);              // H5 兜底
        if (all) XposedBridge.log(TAG + " hooks installed");
        return all;
    }

    private void ensureCtx() {
        if (appCtx != null) return;
        try {
            Class<?> a3 = Class.forName(C_SDK_A3, false, cl);
            Object c = XposedHelpers.getStaticObjectField(a3, "a");
            if (c instanceof Context) {
                appCtx = ((Context) c).getApplicationContext();
                sp = appCtx.getSharedPreferences("WxLuckyCfg", Context.MODE_PRIVATE);
            }
        } catch (Throwable t) { XposedBridge.log(TAG + " ctx fail " + t); }
    }

    /* ========================= 通用反射工具 ========================= */
    private static Class<?> c(String n) throws Throwable { return Class.forName(n, false, cl); }

    private boolean hookSilent(String cls, String mtd, final int argc) {
        try {
            Class<?> k = c(cls);
            XposedBridge.hookAllMethods(k, mtd, new XC_MethodHook() {
                @Override protected void afterHookedMethod(MethodHookParam p) {
                    try {
                        if (p.args == null || p.args.length != argc) return;
                        dispatch(cls, mtd, p);
                    } catch (Throwable t) { XposedBridge.log(TAG + " hook err " + t); }
                }
            });
            return true;
        } catch (Throwable t) { return false; }
    }

    private void dispatch(String cls, String mtd, MethodHookParam p) {
        if (C_MSG_STORAGE.equals(cls))        onNewMessage(p.args[0]);              // H1
        else if (C_NOTIFY.equals(cls))        onNewMessage(p.args[0]);              // H5
        else if (C_NET_BASE.equals(cls))      onNetBaseEnd(p);                      // H2
        else if (C_RECV.equals(cls))          onRecvEnd(p.thisObject);              // H3
        else if (C_OPEN.equals(cls))          onOpenEnd(p.thisObject);              // H4
    }

```java
    /* ========================= H1/H5：新消息 → 红包识别 ========================= */
    private void onNewMessage(Object msg) {
        ensureCtx();
        if (msg == null) return;
        int type   = intOf(XposedHelpers.callMethod(msg, "getType"));
        int isSend = intOf(XposedHelpers.callMethod(msg, "z0"));
        if (isSend != 0) return;                                   // 只处理"收到"的消息

        String talker = str(XposedHelpers.callMethod(msg, "N0"));  // 会话 id
        String raw    = str(XposedHelpers.callMethod(msg, "j"));   // 原始 content（群带 "wxid:" 前缀）
        String xml    = str(XposedHelpers.callMethod(msg, "N1"));  // 去前缀正文 XML
        if (TextUtils.isEmpty(talker) || TextUtils.isEmpty(xml)) return;
        if (type != MSG_TYPE_HONGBAO && !(type == MSG_TYPE_APPMSG && looksLikeHongbao(xml))) return;

        String nativeUrl = cdata(xml, "nativeurl");
        if (TextUtils.isEmpty(nativeUrl)) nativeUrl = cdata(xml, "receivernativeurl");
        if (TextUtils.isEmpty(nativeUrl) || !nativeUrl.contains("receivehongbao")) return;

        String sendId = query(nativeUrl, "sendid");
        if (TextUtils.isEmpty(sendId)) return;
        int channelId = 1;
        try { channelId = Integer.parseInt(query(nativeUrl, "channelid")); } catch (Throwable ignored) {}

        boolean isRoom = talker.endsWith("@chatroom");
        String sender  = isRoom ? roomSender(raw) : talker;        // 群聊发送者 / 私聊对方
        String exclusive = cdata(xml, "exclusive_recv_username");  // 专属红包指定领取人

        log("hongbao talker=" + talker + " sender=" + sender + " sendId=" + sendId
            + " channel=" + channelId + " scene=" + cdata(xml, "sceneid"));

        /* --- 专属红包：不是指定给我的一律不抢 --- */
        String self = callStaticStr(C_CFG_LOGIC, "u");
        if (!TextUtils.isEmpty(exclusive) && !exclusive.equals(self)) {
            log("exclusive hongbao, not mine (" + exclusive + "), skip");
            return;
        }
        /* --- 白名单 / 黑名单 --- */
        if (!shouldGrab(talker, sender)) { log("filtered by white/black list"); return; }

        /* --- 防重：同一 sendId 只处理一次；本地已领过的直接跳过 --- */
        long now = System.currentTimeMillis();
        Long last = LAST_HANDLE.get(sendId);
        if (last != null && now - last < DEDUPE_WINDOW_MS) return;
        LAST_HANDLE.put(sendId, now);
        if (isAlreadyReceived(nativeUrl)) { log("already received in local db, skip"); return; }

        Pending pd = new Pending();
        pd.sendId = sendId; pd.nativeUrl = nativeUrl; pd.channelId = channelId;
        pd.scene  = cdata(xml, "sceneid");                    // 用于判定 union(1005)
        pd.session = talker;                 // ★ 群=聊天厅id / 私聊=对方wxid（openwxhb 的 sessionUserName）
        pd.talker = talker;   pd.sender = sender; pd.isRoom = isRoom;
        pd.msgId  = longOf(XposedHelpers.callMethod(msg, "getMsgId"));
        pd.create = longOf(XposedHelpers.callMethod(msg, "getCreateTime"));
        PENDING.put(sendId, pd);
        doGrab(pd);
    }

    private static boolean looksLikeHongbao(String xml) {
        return xml.contains("<wcpayinfo>") || xml.contains("<wcpaythirdinfo>")
            || xml.contains("receivehongbao") || xml.contains("<nativeurl>");
    }

    /** 群消息原始 content 形如 "wxid_xxx:\n<msg>...</msg>"，取冒号前的发送者 */
    private static String roomSender(String raw) {
        if (TextUtils.isEmpty(raw) || raw.startsWith("<")) return "";
        int i = raw.indexOf(':');
        if (i <= 0 || i > 40) return "";
        return raw.substring(0, i).trim();
    }

    /** mode: 0=全部 1=白名单 2=黑名单；命中条件：talker 或 sender 在名单里 */
    private boolean shouldGrab(String talker, String sender) {
        if (sp == null) return true;
        int mode = sp.getInt("mode", 0);
        if (mode == 0) return true;
        Set<String> list = sp.getStringSet("list", new HashSet<String>());
        boolean hit = list.contains(talker) || (!TextUtils.isEmpty(sender) && list.contains(sender));
        return mode == 1 ? hit : !hit;
    }

    /** 读微信本地"红包记录"表：已领过(field_receiveAmount>0)就跳过 */
    private boolean isAlreadyReceived(String nativeUrl) {
        try {
            Object plugin = XposedHelpers.callStaticMethod(c("ph5.n0"), "c", c("lj0.a3"));
            if (plugin == null) return false;
            Object dao = XposedHelpers.callMethod(plugin, "ij");        // v05.x
            Object rec = XposedHelpers.callMethod(dao, "t1", nativeUrl);// s05.k1 / im.ec
            if (rec == null) return false;
            Object amt = XposedHelpers.getObjectField(rec, "field_receiveAmount");
            return amt instanceof Number && ((Number) amt).longValue() > 0;
        } catch (Throwable t) { return false; }
    }

    /* ========================= 提交：receivewxhb → openwxhb ========================= */
    private void doGrab(final Pending pd) {
        final long dmin = sp == null ? 200 : sp.getInt("delay_min", 200);
        final long dmax = sp == null ? 900 : sp.getInt("delay_max", 900);
        WORKER.execute(new Runnable() { public void run() {
            try { Thread.sleep(dmin + (long) (Math.random() * Math.max(1, dmax - dmin))); } catch (Throwable ignored) {}
            try {
                Object recv = newInstance(C_RECV,
                        new Class<?>[]{int.class, int.class, String.class, String.class, int.class, String.class, String.class},
                        1 /*msgType*/, pd.channelId, pd.sendId, pd.nativeUrl, 0 /*inWay*/, "v1.0", pd.session);
                if (recv == null) { log("new n6 fail"); PENDING.remove(pd.sendId); return; }
                MY_SCENES.add(recv);
                submitScene(recv);
                log("receivewxhb sent: " + pd.sendId);
            } catch (Throwable t) { log("doGrab err " + t); PENDING.remove(pd.sendId); }
        }});
    }

    /** 把 scene 丢进微信自己的网络队列：gp0.j1.j().q().b.g(scene) */
    private void submitScene(Object scene) throws Throwable {
        Object kernel = XposedHelpers.callStaticMethod(c(C_KERNEL), "j");
        Object engine = XposedHelpers.callMethod(kernel, "q");            // gp0.y
        Object queue  = XposedHelpers.getObjectField(engine, "b");        // modelbase.r1
        XposedHelpers.callMethod(queue, "g", scene);
    }

    private Object newInstance(String cls, Class<?>[] sig, Object... args) {
        try {
            Constructor<?> ctor = c(cls).getDeclaredConstructor(sig);
            ctor.setAccessible(true);
            return ctor.newInstance(args);
        } catch (Throwable t) { log("newInstance " + cls + " err " + t); return null; }
    }
```

```java
    /* ========================= H2：统一出口（错误/风控/超时） ========================= */
    private void onNetBaseEnd(MethodHookParam p) {
        Object scene = p.thisObject;
        if (!MY_SCENES.contains(scene)) return;                 // 只关心自己的 scene
        int errType = ((Number) p.args[1]).intValue();
        int errCode = ((Number) p.args[2]).intValue();
        String errMsg = str(p.args[3]);
        if (errType == 0 && errCode == 0) return;               // 成功走 H3/H4
        Pending pd = pendingOf(scene);

        if (pd != null) {
            PENDING.remove(pd.sendId);
            notifyGrab(pd, -1L, null, "失败 " + errCode + " " + errMsg);
        }

    /* ========================= H3：receivewxhb 响应 → 拿 timingIdentifier ========================= */
    private void onRecvEnd(Object scene) {
        if (scene == null || !MY_SCENES.contains(scene)) return;
        String sendId  = str(XposedHelpers.getObjectField(scene, "m"));
        String nurl    = str(XposedHelpers.getObjectField(scene, "n"));
        int msgType    = XposedHelpers.getIntField(scene, "h");     // = 1
        int channel    = XposedHelpers.getIntField(scene, "i");     // = nativeUrl 里的 channelid
        String timing  = str(XposedHelpers.getObjectField(scene, "P"));  // ★ timingIdentifier
        int hbStatus   = XposedHelpers.getIntField(scene, "s");
        int recvStat   = XposedHelpers.getIntField(scene, "t");
        String statusMess = str(XposedHelpers.getObjectField(scene, "u"));
        Pending pd = sendId == null ? null : PENDING.get(sendId);
        if (pd == null) pd = pendingOf(scene);
        if (pd == null) return;

        if (recvStat == 2 || hbStatus == 4 || hbStatus == 5) {      // 已领过/已过期/已撤
            log("hb not available: hbStatus=" + hbStatus + " recv=" + recvStat + " " + statusMess);
            PENDING.remove(pd.sendId);
            notifyGrab(pd, -1L, null, TextUtils.isEmpty(statusMess) ? "已领过/已过期" : statusMess);
            return;
        }
        if (TextUtils.isEmpty(timing)) { log("timingIdentifier empty, give up"); PENDING.remove(pd.sendId); return; }

        String headImg = callStaticStr(C_LUCKY_UTIL, "l");     // o5.l()  自己头像
        String nick    = callStaticStr(C_CFG_LOGIC, "m");      // y1.m()  自己昵称

        if (open == null) { PENDING.remove(pd.sendId); return; }
        MY_SCENES.add(open);
        submitScene(open);
        log("openwxhb sent: " + sendId + " timing=" + timing);
    }

    private void onOpenEnd(Object scene) {
        if (scene == null || !MY_SCENES.contains(scene)) return;
        Object e1 = XposedHelpers.getObjectField(scene, "h");        // i5.d(json) 的结果
        if (e1 == null) return;

        long totalNum    = getLong(e1, "t");
        long totalAmount = getLong(e1, "u");
        Pending pd = pendingOf(scene);
        log("opened: amount=" + amountFen + " fen, nick=" + sendNick + " recv=" + recvStatus
            + " recNum=" + recNum + "/" + totalNum + " msg=" + statusMess);

        if (pd != null) PENDING.remove(pd.sendId);
        if (amountFen > 0) {
            String who = TextUtils.isEmpty(sendNick) ? sendUser : sendNick;

                       recNum + "/" + totalNum + "个 · 共" + fmtFen(totalAmount));
            // 可选：这里再发 x5(qrydetailwxhb) 拉领取详情
        } else {
            notifyGrab(pd, -1L, TextUtils.isEmpty(sendNick) ? sendUser : sendNick,
                       TextUtils.isEmpty(statusMess) ? ("状态码 " + recvStatus) : statusMess);
        }
    }

    /* ========================= 小工具 ========================= */
    private static String cdata(String xml, String tag) {
        if (xml == null || tag == null) return null;
        java.util.regex.Matcher m = java.util.regex.Pattern
                .compile("<" + tag + ">\\s*(?:<!\\[CDATA\\[)?(.*?)(?:\\]\\]>)?\\s*</" + tag + ">",
                         java.util.regex.Pattern.DOTALL).matcher(xml);
        return m.find() ? m.group(1).trim() : null;
    }

    private static String query(String url, String key) {
        if (url == null) return null;
        int q = url.indexOf('?');
        if (q < 0) return null;
        for (String kv : url.substring(q + 1).split("&")) {
            int i = kv.indexOf('=');
            if (i > 0 && kv.substring(0, i).equals(key)) return kv.substring(i + 1);
        }
        return null;
    }

    private static int  getInt(Object o, String f)  { try { return XposedHelpers.getIntField(o, f); } catch (Throwable t) { return 0; } }
    private static long getLong(Object o, String f) { try { return XposedHelpers.getLongField(o, f); } catch (Throwable t) { return 0L; } }

        catch (Throwable t) { return ""; }
    }
```

## 6. 兼容性、动态定位与风险（务必读）

### 6.1 类名/字段名是混淆的，换版本会变

本版本 `com.tencent.mm.plugin.luckymoney.model.h6 / n6 / i6 / x5 / y5 / o5 / q5` 本身就是**混淆后的短名**（同一 dex 内还有 `a0..z3` 一大堆）。换一个微信构建，这些名字大概率会变；但下面这些东西**长期稳定**：

| 稳定锚点 | 值 |
|---|---|
| CGI URI 字符串 | `/cgi-bin/mmpay-bin/receivewxhb`、`/cgi-bin/mmpay-bin/openwxhb`、`/cgi-bin/mmpay-bin/qrydetailwxhb`、`/cgi-bin/mmpay-bin/unionhb/*` |
| 请求参数 key | `msgType/channelId/sendId/nativeUrl/headImg/nickName/sessionUserName/ver/timingIdentifier/left_button_continue/inWay/agreeDuty/group_name` |
| 响应 JSON key | `timingIdentifier/hbStatus/receiveStatus/hbType/sendNick/sendUserName/amount/recNum/recAmount/totalNum/totalAmount/receiveId/receiveStatus/statusMess` |

### 6.2 运行时动态定位（DexKit 兜底，替代写死 h6/n6）

```java
// 1) 用 CGI 字符串定位 NetScene 类
DexKit kit = DexKit.builder(context).build();
Map<String, List<ClassData>> r = kit.batchFindClassUsingStrings(b -> {
    b.addSearchGroup("recv").usingStrings = Arrays.asList("/cgi-bin/mmpay-bin/receivewxhb");

}, res -> {
    // openCb 即 openwxhb 的 onGYNetEnd(int,String,JSONObject)：第三个参数就是原始响应 JSON
});
```
**关键技巧：响应解析不要读混淆字段，直接读 hook 到的 `JSONObject`**（`param.args[2]`）：

```java
// hook 上面定位到的 openCb（h6.onGYNetEnd）
JSONObject json = (JSONObject) param.args[2];
long amount  = json.optLong("amount");             // 分，等价于 e1.q

```
这样即使 `e1` 的字段名（`q/i/A/f`…）变了也照常工作。

**headImg/nickName 的热学习兜底**：hook `openCb` 所在类的 `<init>(II + 8 String)`，用户手动点开红包时把 `args[4]/args[5]`（headImg/nickName）缓存下来，之后自己的请求复用；若从未手动抢过就传 `""`（`h6` 构造函数对空 headImg 有分支：**空则整个不带 headImg/nickName**，代码上是允许的）。

### 6.3 其它工程注意点

1. **多 dex / 类加载**：`com.tencent.mm.plugin.luckymoney.*` 在主 dex 或插件 dex，`f9/e9` 在主 dex。用 `lpparam.classLoader` + **失败重试**（代码里 `ensureHooks(attempt)`），不要指望 `handleLoadPackage` 那一刻一定能 load。
2. **线程**：`r1.g()` 是线程安全的，但**不要在 hook 线程里 sleep**（会卡微信），一律丢自己的 `WORKER` 线程。
3. **不要并发抢同一个 sendId**：`MY_SCENES + PENDING + LAST_HANDLE` 三重去重；微信侧 `r1.h()` 对 `uniqueInNetsceneQueue()` 的场景还会自动去重。
4. **已领/过期判断**：`receiveStatus == 2`（已领过）、`hbStatus == 4/5`（过期/撤回）→ 直接放弃并发"已领过"通知，别重复打 CGI（容易触发风控）。
5. **专属红包**：`exclusive_recv_username` 非自己 wxid 时**必须跳过**，否则也是失败请求。
6. **风控/频率**：务必保留随机延迟（建议 200~1500ms，可配置）；同一会话短时间大量领取极易触发"手速过快/账号异常"。
7. **SO/壳**：若目标 APK 有整体加固，`findClass` 可能拿不到 dex，需要等微信自行加载后再 hook（重试机制已覆盖大多数情况）。
8. **通知**：Android 13+ 需要 `POST_NOTIFICATIONS`；频道建一次即可；点击通知用 `getLaunchIntentForPackage("com.tencent.mm")` 拉起微信。
9. **多个 Xposed 模块共存**：我们只 hook 不 patch，不与其它模块冲突；`MY_SCENES` 保证不会误吞用户自己手动抢红包的回调。
