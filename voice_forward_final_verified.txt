一、g() 做了什么（y21.x0.g 源码17行）
================================================================================

  g(talker, "amr_"):
    ① g1.x0(z1.r(), "amr_") → "amr_<timestamp>"  生成文件名
    ② new w0() → 设 b=文件名 c=talker j/k=时间 i=1 n=wxid a=-1
    ③ O0(w0) → INSERT voiceinfo 表
    ④ 返回 "amr_<timestamp>"

  注意: w0.x = null（g()没设），这会影响后面 hj() 的路由


二、t() 做了什么（y21.x0.t Smali 286行）
================================================================================

  t(fileName, duration, flag, refMsg):
    ① j(fileName) → w0        查 w0（必须存在，否则 return false）
    ② w0.i 检查               i≠97/98 → 自动设 i=3（完成）
    ③ v0.d(null, fileName)    ★ 测时长（返回0则 return false）
    ④ 更新 w0: k=时间, l=duration, a=0x400d60
    ⑤ new e9() → setType(34) → k1(1) → j1(fileName)
       → d1(u0.c(sender, duration, false))  语音XML
       → e1(createTime) → o3(flag)
    ⑥ po.b.d(e9)             写 message 表
    ⑦ w(w0)                  更新 voiceinfo 表


三、v0.d() → h1.d() 路径计算公式（已验证）
================================================================================

  v0.d(null, fileName):
    → h90.b.Lj(null, fileName, false)
      → ev.p0.hj(y, fileName, null, false, false, pString)
        → ev.p0.lj(y, fileName, false)  ← 因为 w0.x=null, 走旧路径
          → h1.d(voice2+"/", "msg_", fileName, ".amr", 2, false)

  h1.d() 公式:
    subdir = h1.b(kk.k.g(fileName.getBytes()))  // MD5前4字 → "XX/YY/"
    path = voice2/XX/YY/msg_<fileName>.amr

  例: fileName = "amr_1016150725267af029044ae100"
      MD5("amr_1016150725267af029044ae100") = ...
      path = voice2/<2>/<2>/msg_amr_1016150725267af029044ae100.amr

  关键: 路径格式是 "msg_amr_<timestamp>.amr"，不是 "msg_<cid>.amr"!
        源语音文件是 "msg_<clientMsgId>.amr"，完全不同!


四、为什么之前都失败
================================================================================

  你手动复制源文件到 voice2/XX/YY/msg_<cid>.amr
  但 t() 在 v0.d() 中通过 h1.d() 查找的是:
    voice2/XX/YY/msg_amr_<timestamp>.amr  ← 文件名不同!

  所以 w6.B() 打开失败 → v0.b() 返回1 → v0.f() 返回0 → t() → s()删w0 → false
