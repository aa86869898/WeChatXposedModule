b31.w 数据传入分析 — 微信 8.0.76

完整类名: b31.w
日志Tag: "MicroMsg.SceneVoiceInputAddr"

这不是语音消息上传器！它是 语音输入/识别 (voice input addr)。

34个字段 + 数据传入方式:

[数据传入 — 3种方式]
  方式1: 构造时传入
    w(int type, int scene, b31.b callback)
    w(int,int,String,String,String,b70.w,b31.b)  ← 含talker/filePath/MD5

  方式2: init(scene, type, callback)
    void init(int i, int i2, b bVar)
      → this.s = i (scene), this.h = i2 (type), this.t = bVar (callback)

  方式3: 直接设字段
    sender.L = "wxid_xxx";        // toUser
    sender.B = "/voice2/xxx.amr"; // voice file path
    sender.m = 5000;              // duration(ms)
    sender.e = 34;                // type=语音

[关键字段]
  L: String      toUser/目标用户
  M: String      content/识别文本
  B: String      语音文件路径
  m: int         时长(ms)
  e: int         消息类型(34=语音)
  d: int         场景
  s: int         场景(init设)
  h: int         类型(init设)
  t: b31.b       结果回调(init设)

注意: b31.w 是语音输入识别，不是语音消息上传。
转发语音不需要 b31.w!
正确流程: g()+复制文件→voice2 + t()+tl.q0.e()
