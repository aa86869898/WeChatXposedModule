1. b31.w   →   语音上传 NetScene 管理器
───────────────────────────────────────
  完整类名: b31.w

  Xposed: XposedHelpers.findClass("b31.w", classLoader)

  构造:
    w()                                  无参
    w(int type, int scene, b31.b callback)    3参数

    void start()                              开始上传
    void start(String voicePath)              指定路径上传
    void stop(boolean)                        停止上传
    void cancel(boolean)                      取消上传
    void init(int, int, b31.b)                初始化
    void init(boolean, boolean, int, int, b31.b) 完整初始化
    void f(boolean, boolean, b31.d)           发送参数设置
    void d(boolean, boolean)                  设置参数
    void onSceneEnd(int errType, int errCode, String errMsg, m1 scene) 网络回调
    int getMaxAmplitudeRate()                 最大振幅
    void setVadSAndNRation(float)             VAD信噪比
    String b()                               获取某字符串

  推测位置: 可能是 y21.* 包下的类 (如 y21.g1 或类似)
            在 tl.p0 的 import 中可能被导入为别名 x0

  y21.g1 (疑似 x0):
    完整类名: y21.g1
    构造: g1(s85.k0)
    方法:
      static String x0(String prefix, String ext)  生成随机文件名
      static String y0(long)                       另一种文件名生成
      static w0 F0(String)                        获取文件信息
      static w0 H0(String)
      static w0 I0(long)
      static w0 N0(String, long)
      static boolean O0(w0)                       检查文件信息
      static boolean Q0(String, w0)
      static boolean d(String)                    可能是删除
      static void t0(y, String)                   可能是更新DB

  另一个 x0 (可能在 y21 或 voice 相关包):
    方法参考(从 tl.p0.stop() 反推):
      static ? x0.g(String talker, String prefix) → 生成文件路径
      static void x0.b(String path)               → 删除/清理
      static void x0.t(String path, int duration, int zero, e9 msg) → 更新DB

  实际查找方法:

4. po   →   可能是指 tl.p0 或 y21.p0 (播放列表)
───────────────────────────────────────
  如果 "po" 是指 tl.p0:
    见上 #2

  如果 "po" 是指 y21.p0 (Voice Playlist Manager):
    tl.p0.stop() 源码中有:
      y21.p0.kj().e()   → 语音播放列表刷新

    方法: kj() → 获取某实例
