二、type 值含义 (从微信源码验证)
================================================================================

  getType() 返回 this.field_type，在 rcontact 表中:

  type  │ 含义               │ 过滤策略
  ──────┼───────────────────┼────────────────
    0   │ 正常好友 ✓        │ 保留
    1   │ 对方未添加         │ 过滤(非好友)
    2   │ 被对方删除         │ 过滤(非好友)
    3   │ 已删除对方         │ 过滤(非好友)
    4   │ 已拉黑对方         │ 过滤(非好友)

三、精准 SQL 过滤规则
================================================================================

  [规则1] 仅好友 (type=0, 排除群聊账户和公众号)
  ───────────────────────────────────────────
  SELECT username, nickname, alias, conRemark, type, sex
  FROM rcontact
  WHERE deleteFlag=0
    AND type=0
    AND username NOT LIKE '%@chatroom'
    AND username NOT LIKE 'gh_%'
  ORDER BY nickname

  [规则2] 好友 + 性别筛选
  ──────────────────────
  WHERE deleteFlag=0 AND type=0
    AND username NOT LIKE '%@chatroom'
    AND sex=1              -- 1=男, 2=女, 0=未知

  [规则3] 仅群聊账户
  ──────────────────
  WHERE type=0 AND username LIKE '%@chatroom'

  [规则4] 已删除/拉黑的人
  ─────────────────────
  WHERE deleteFlag=0 AND type IN (2,4)

  [规则5] 全部联系人(含非好友, 排除群和公众号)
  ─────────────────────────────────────────
  WHERE deleteFlag=0
    AND username NOT LIKE '%@chatroom'
    AND username NOT LIKE 'gh_%'

四、username 后缀规则
================================================================================

  后缀              │ 类型           │ 过滤策略
  ──────────────────┼───────────────┼──────────
  @chatroom         │ 群聊账户       │ 排除
  gh_               │ 公众号         │ 排除
  @openim           │ OpenIM账户     │ 排除
  @stranger         │ 陌生人         │ 排除
  @app              │ 应用账户       │ 排除
  @talkroom         │ 语音聊天室     │ 排除
  @lbsroom          │ LBS聊天室      │ 排除
  wxid_             │ 好友/非好友    │ 保留(正常用户)
  其他自定义号       │ 好友/非好友    │ 保留
