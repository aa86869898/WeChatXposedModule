## 一、本轮新发现的 5 处缺陷（已修正）

### 缺陷 1 ★★★（致命）：`SnsObject.parseFrom()` 返回值被丢弃

**原代码（错）**：
```java
Object snsObject = XposedHelpers.newInstance(snsObjCls);
XposedHelpers.callMethod(snsObject, "parseFrom", (Object) attr);   // ← 返回值被丢，snsObject 是空对象！
```

**证据**：`decompile_method(h6, "a")` 的官方写法
```java
SnsInfo a = l1.a(str);
SnsObject parseFrom = new SnsObject().parseFrom(((ua) a).field_attrBuf);
Iterator it = parseFrom.LikeUserList.iterator();
```
→ 微信 protobuf-lite 的 `parseFrom` 是**实例方法、返回新对象**（不是 fill-in-place）。

**修正**：
```java
Object snsObject = XposedHelpers.callMethod(
        XposedHelpers.newInstance(snsObjCls), "parseFrom", (Object) attr);
if (snsObject == null) return false;
```
> 已就地修正到 01 文件 §9.2。

### 缺陷 2 ★★：`findClass(...)` 未定义

01 文件 §9.2 / §9.3 / §10.2 / §11.1 / §12 / §14 大量裸用了 `findClass("xxx", cl)`，但没有定义该辅助方法，无法直接编译。
→ 已全部替换为 `XposedHelpers.findClass("xxx", cl)`。

### 缺陷 3 ★★：§12 的 `findAndHookMethod` 传 `Class<?>[]` 有展开风险

XposedHelpers 的 `findAndHookMethod(String, ClassLoader, String, Object...)` 要求 parameter types **逐个展开**，把 `Class<?>[]` 当单个 Object 传会解析失败。
→ 修正写法见 §四（完整可用代码），**不再使用 `concat()` 辅助**。

### 缺陷 4 ★：`ContactStorage` 类名不确定

01 文件 §10.2 写了 `com.tencent.mm.storage.i4` = ContactStorage，但**未经核实**（`search_classes("ContactStorage")` 只做了 DexKit 字符串回退，结果含大量无关类）。
→ 已删除该段，改为"昵称兜底策略"（直接用 wxid 当显示名，微信只渲染字符串，功能完全等价）。

### 缺陷 5 ★：编造了资源 ID 的十六进制形式

01 文件正文中出现了 `0x7f0b05c1` / `0x7f0b6905`，这是笔者推算的，**工具从未给出**。
→ 统一改用工具确认的十进制值（下表），删除所有自算 hex。

## 三、补全 2：`MMPopupMenu` 全量入口（必须全 hook）

第一轮列了 6 个，本轮核对 smali 后确认为 **8 个公开入口 + 4 个内部 OnLongClickListener**：

```smali
.method public h(Landroid/view/View;Landroid/view/View$OnCreateContextMenuListener;Lkj5/v4;II)V   # ★ show（普通 View）
.method public h(Landroid/view/View;Lkj5/p4;Lkj5/v4;II)V                                            # ★ show（p4 重载）
.method public g(Landroid/view/View;IJLandroid/view/View$OnCreateContextMenuListener;Lkj5/v4;II)V    # ★ show（adapter + id）
.method public f(Landroid/view/View;Lkj5/p4;Lkj5/v4;II)V                                            # show（p4 重载）
.method public j(Landroid/view/View;Landroid/view/View$OnCreateContextMenuListener;Lkj5/v4;)V         # ★ register（普通 View）
.method public i(Landroid/view/View;Lkj5/p4;Lkj5/v4;)V                                              # register（p4 版）
```

**内部匿名 OnLongClickListener**（`j()`/`i()` 注册产生，长按时才调 `onCreateContextMenu`）:

```smali
Leu5/g0;-><init>(Leu5/s0;Landroid/view/View$OnCreateContextMenuListener;)V     # MMPopupMenu$2  普通 View
Leu5/i0;-><init>(Leu5/s0;Lkj5/p4;Landroid/view/View;)V                        # MMPopupMenu$4  p4 版
Leu5/f0;-><init>(Leu5/s0;Landroid/view/View$OnCreateContextMenuListener;)V     # MMPopupMenu$1  AbsListView
Leu5/h0;->...                                                                  # AbsListView(p4)
```

`eu5.g0#onLongClick` 关键代码（证明 hook `j()` 的第 2 参数有效）：
```java
s0Var.x.clear();
s0Var.f = view;
this.d.onCreateContextMenu(s0Var.x, view, null);      // ← this.d = 你在 j() 传入的 listener
if (view.getTag(2131389505) instanceof int[]) { ... s0Var.n(iArr[0], iArr[1]); }
else s0Var.m();

```

**朋友圈实际只用到 `h` / `g` / `j`**（`i`/`f` 的调用者 `c04.c0/d0/j3.x`、各种 finder/chatting 类，与 sns 无关），但为防微信改版，**建议 6 个全 hook**。

### `kj5.p4` 接口（`i()`/`f()` 路径用）

```java

    void a(kj5.i4 menu, View v, ContextMenu.ContextMenuInfo info);
```

若走 `i()`/`f()` 路径，需要 hook `kj5.p4` 的实现类的 `a(...)`。朋友圈暂无此路径，可暂不处理。

```java
public class FakeLikeInjector implements IXposedHookLoadPackage {
```

## 七、补全 5：`FakeLikeEngine`（伪造 + 刷新，独立可编译）

```java
public final class FakeLikeEngine {
    static ClassLoader cl;

    /* 伪造点赞列表 */
    public static boolean fakeLike(Object snsInfoObj, List<String[]> pairs) {
        try {
            byte[] attr = (byte[]) XposedHelpers.getObjectField(snsInfoObj, "field_attrBuf");
            if (attr == null || attr.length == 0) return false;

            Class<?> soCls = XposedHelpers.findClass("com.tencent.mm.protocal.protobuf.SnsObject", cl);
            Object snsObj = XposedHelpers.callMethod(XposedHelpers.newInstance(soCls), "parseFrom", attr);
            if (snsObj == null) return false;

            @SuppressWarnings("unchecked")
            LinkedList<Object> list = (LinkedList<Object>) XposedHelpers.getObjectField(snsObj, "LikeUserList");
            Class<?> uf6 = XposedHelpers.findClass("pc5.uf6", cl);

            int added = 0;
            for (String[] p : pairs) {
                String wxid = p[0], nick = p[1];
                boolean dup = false;
                for (Object o : list) if (wxid.equals(XposedHelpers.getObjectField(o, "d"))) { dup = true; break; }
                if (dup) continue;

                Object it = XposedHelpers.newInstance(uf6);
                XposedHelpers.setObjectField(it, "d", wxid);           // wxid
                XposedHelpers.setObjectField(it, "e", nick);           // 昵称
                XposedHelpers.setObjectField(it, "h", "");             // 内容
                XposedHelpers.setObjectField(it, "o", "");             // 无回复对象
                XposedHelpers.setObjectField(it, "g", 5);              // 5=陌生人赞；1=好友赞
                XposedHelpers.setObjectField(it, "f", 0);              // scene
                XposedHelpers.setObjectField(it, "t", 0);              // flag
                int now = (int) (System.currentTimeMillis() / 1000);
                XposedHelpers.setObjectField(it, "i", now);
                XposedHelpers.setObjectField(it, "m", now);
                list.addFirst(it);                                    // 新赞排最前
                added++;
            }
            if (added == 0) return false;

            int cnt = list.size();
            XposedHelpers.setObjectField(snsObj, "LikeCount", cnt);
            XposedHelpers.setObjectField(snsObj, "LikeUserListCount", cnt);

            byte[] out = (byte[]) XposedHelpers.callMethod(snsObj, "toByteArray");
            if (out == null || out.length == 0) return false;
            XposedHelpers.setObjectField(snsInfoObj, "field_attrBuf", out);
            XposedHelpers.callMethod(snsInfoObj, "setAttrBuf", out);

            Object store = XposedHelpers.callMethod(
                    XposedHelpers.callStaticMethod(
                        XposedHelpers.findClass("com.tencent.mm.plugin.sns.model.p4", cl), "jj"), "Jj");
            XposedHelpers.callMethod(store, "w4", snsInfoObj);
            return true;
        } catch (Throwable t) {
            XposedBridge.log("[FakeLike] fakeLike: " + t);
            return false;
        }
    }

    /* 恢复原始 attrBuf（建议你的模块启用前先备份） */

        if (backup == null) return;
```

## 九、仍待你本地验证的三点（工具无法静态确定）

1. **`SnsInfo.field_attrBuf` 的可见性**：字段定义在父类 `lim.ua`，`XposedHelpers.getObjectField/setObjectField` 会向上遍历父类，正常可用；若你的 Xposed 版本报 `NoSuchFieldError`，改用 `XposedHelpers.findField(snsInfoObj.getClass(), "field_attrBuf")` 再 `setAccessible(true)`。
2. **刷新是否立即生效**：`SnsTimelineRefreshEvent` 是通过 EventCenter 字符串索引分发的，`find_class_usage` 查不到订阅者（正常现象）。若列表不刷新，重进"发现 → 朋友圈"即可看到落库结果（数据一定已写库）。
3. **`menu.add(1000, FAKE_ID, 99, "伪集赞")` 的 groupId=1000**：原生菜单最大 groupId=1，用 1000 可确保不冲突；若微信版本校验了 groupId，改用 groupId=0 也行（itemId 唯一即可）。
