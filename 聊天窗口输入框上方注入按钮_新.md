我已经完成了对微信聊天界面底部栏及其容器结构的分析。下面给你一份"地毯式"的结论 + 可直接用的 Java Xposed 实现。
一、总体结论（先看这里）
要在微信聊天窗口"输入框/底部栏上方"注入一排功能按钮，不需要改布局文件，正确做法是：
1.  
Hook 底部栏视图  ChatFooter  的构造器（或 hook  ChattingUIFragment.onResume ）
2.  
在它 attach 到窗口后，向它的父容器插入一个横向按钮栏（插在  ChatFooter  之前的位置）
3.  
 ChatFooter  的父容器是  ChattingUILayout ，继承自垂直 LinearLayout，所以"插到 footer 前面"天然就是"输入框上方"，且会随键盘自动上移，效果最理想。
二、地毯式类/方法分析
1. 入口 Activity / Fragment 链
 com.tencent.mm.ui.chatting.ChattingUI 
聊天窗口 Activity
 onCreate 、 onResume 、 o7()  返回  ChattingUIFragment 
 com.tencent.mm.ui.chatting.ChattingUIFragment 
聊天窗口 Fragment（真身）
 getLayoutView()  返回根布局、 dealContentView() 
 com.tencent.mm.ui.chatting.BaseChattingUIFragment 
Fragment 基类
 onResume() 、 onCreateView() 、 onActivityCreated() 
 com.tencent.mm.ui.MMFragment 
更上层基类
 getContentView()  →  mController.w() 
关键证据： ChattingUIFragment.getLayoutView()  用布局 id  2131624731 （即  0x7F0E031B ）inflate 出整个聊天窗口根视图：

2. 底部栏本体： com.tencent.mm.pluginsdk.ui.chat.ChatFooter 
•  
类型： android.widget.FrameLayout ，实现接口  k9 / e5 / a ，是整条"输入框 + 表情/更多面板"的宿主。
•  
类规模：字段 330+，方法 300+，smali 近 3.7 万行，字段名全部混淆（ j5 、 g6 、 P5 …），不能依赖具体字段名做 hook。
•  
重要字段（从 smali 中确认）：
•  
 j5 : Lcom/tencent/mm/ui/widget/MMEditText;  → 输入框本体（设置文字用它）
•  
 g6 : View  → 语音转文字条
•  
 C2 : ChattingScrollLayout  → footer 内部滚动容器
•  
 B : d0 、 D : MaxHeightScrollView  → 面板相关
•  
构造器： <init>(Context, AttributeSet, int)  是真正构造器； <init>(Context, AttributeSet)  只是委托调用它 → Hook 三参构造器一次即可覆盖所有创建路径。
•  
创建方式：由布局 XML 通过  <com.tencent.mm.pluginsdk.ui.chat.ChatFooter/>  标签 inflate（不是  new ），所以 DEX 里找不到 INVOKE 引用，只能靠 View 树遍历或 Hook 构造器。
3. 父容器： com.tencent.mm.pluginsdk.ui.chat.ChattingUILayout 
ChattingUILayout
  extends BasePanelKeybordLayout
    extends KeyboardLinearLayout     ← 垂直 LinearLayout！
      extends OnLayoutChangedLinearLayout
•  
它就是聊天窗口底部那块"列表 + 输入栏"的容器，垂直 LinearLayout 布局。
•  
正因为是线性布局，向它  addView(toolbar, indexOfChild(chatFooter))  就能把按钮栏精确插到输入栏正上方，且键盘弹出/收起时由  KeyboardLinearLayout  自动重新测量，无需自己处理键盘高度。
4. 底部栏相关其它类（补充理解）

底部那条最下的横条（FrameLayout），不是主目标
 com.tencent.mm.pluginsdk.ui.chat.AppPanel 
点"+"弹出的功能面板（LinearLayout + GridView）

面板基类（表情/更多等）

三、Java Xposed 实现（可直接用）
java
package com.example.wxhook;

import android.content.Context;
import android.graphics.Color;
import android.graphics.drawable.GradientDrawable;
import android.text.TextUtils;
import android.view.Gravity;
import android.view.View;
import android.view.ViewGroup;
import android.widget.Button;
import android.widget.LinearLayout;
import android.widget.TextView;
import android.widget.Toast;

import java.util.ArrayList;
import java.util.WeakHashMap;

import de.robv.android.xposed.IXposedHookLoadPackage;
import de.robv.android.xposed.XC_MethodHook;
import de.robv.android.xposed.XposedHelpers;
import de.robv.android.xposed.callbacks.XC_LoadPackage;

public class WxHook implements IXposedHookLoadPackage {

    private static final String PKG = "com.tencent.mm";
    private static final String CHAT_FOOTER = "com.tencent.mm.pluginsdk.ui.chat.ChatFooter";
    private static final String CHAT_UI_LAYOUT = "com.tencent.mm.pluginsdk.ui.chat.ChattingUILayout";
    private static final String BASE_FRAGMENT = "com.tencent.mm.ui.chatting.BaseChattingUIFragment";

    // 防重复注入：WeakHashMap<footer, Boolean>，避免 onResume 反复执行
    private static final WeakHashMap<View, Boolean> sInjected = new WeakHashMap<>();

    @Override
    public void handleLoadPackage(XC_LoadPackage.LoadPackageParam lpparam) {
        if (!PKG.equals(lpparam.packageName)) return;

        // ========== 方案 A（主推）：Hook ChatFooter 构造器 ==========
        try {
            Class<?> footerClazz = XposedHelpers.findClass(CHAT_FOOTER, lpparam.classLoader);
            XposedHelpers.findAndHookConstructor(footerClazz,
                    Context.class, android.util.AttributeSet.class, int.class,
                    new XC_MethodHook() {
                        @Override
                        protected void afterHookedMethod(MethodHookParam param) {
                            final View footer = (View) param.thisObject;
                            // 等它真正 attach 到窗口再插（此时父容器已就绪）
                            footer.addOnAttachStateChangeListener(new View.OnAttachStateChangeListener() {
                                @Override
                                public void onViewAttachedToWindow(View v) {
                                    footer.post(() -> safeInject(footer));
                                }
                                @Override
                                public void onViewDetachedFromWindow(View v) { }
                            });
                        }
                    });
        } catch (Throwable t) {
            // 版本变化时降级到方案 B
            hookFragment(lpparam);
        }

        // ========== 方案 B（兜底）：Hook Fragment onResume ==========
        hookFragment(lpparam);
    }

    private void hookFragment(XC_LoadPackage.LoadPackageParam lpparam) {
        try {
            XposedHelpers.findAndHookMethod(BASE_FRAGMENT, lpparam.classLoader, "onResume",
                    new XC_MethodHook() {
                        @Override
                        protected void afterHookedMethod(MethodHookParam param) {
                            Object fragment = param.thisObject;
                            View root = (View) XposedHelpers.callMethod(fragment, "getView");
                            if (root == null) return;
                            View footer = findFooter(root);
                            if (footer != null) safeInject(footer);
                        }
                    });
        } catch (Throwable ignored) { }
    }

    // ---------- 注入核心 ----------

    private void safeInject(View footer) {
        if (footer == null) return;
        synchronized (sInjected) {
            if (sInjected.containsKey(footer)) return;
            sInjected.put(footer, Boolean.TRUE);
        }
        ViewGroup parent = (ViewGroup) footer.getParent();
        if (parent == null) return;

        final Context ctx = footer.getContext();
        LinearLayout toolbar = buildToolbar(ctx, footer);

        // 父容器是垂直 LinearLayout：插到 footer 前面 == 输入框上方
        if (parent instanceof LinearLayout
                && ((LinearLayout) parent).getOrientation() == LinearLayout.VERTICAL) {
            int idx = parent.indexOfChild(footer);
            parent.addView(toolbar, idx);
        } else {
            // 万一父容器是 FrameLayout：底部对齐 + 留出 footer 高度
            ViewGroup.LayoutParams raw = parent.getLayoutParams();
            LinearLayout.LayoutParams lp = new LinearLayout.LayoutParams(
                    ViewGroup.LayoutParams.MATCH_PARENT, ViewGroup.LayoutParams.WRAP_CONTENT);
            lp.gravity = Gravity.BOTTOM;
            lp.bottomMargin = footer.getHeight() + dp(ctx, 4);
            parent.addView(toolbar, lp);
            footer.addOnLayoutChangeListener((v, l, t, r, b, ol, ot, or, ob) -> {
                lp.bottomMargin = footer.getHeight() + dp(ctx, 4);
            });
        }
    }

    private View findFooter(ViewGroup root) {
        for (int i = 0; i < root.getChildCount(); i++) {
            View c = root.getChildAt(i);
            if (CHAT_FOOTER.equals(c.getClass().getName())) return c;
            if (c instanceof ViewGroup) {
                View r = findFooter((ViewGroup) c);
                if (r != null) return r;
            }
        }
        return null;
    }

    // ---------- 构建按钮栏 ----------

    private LinearLayout buildToolbar(final Context ctx, final View footer) {
        LinearLayout bar = new LinearLayout(ctx);
        bar.setOrientation(LinearLayout.HORIZONTAL);
        bar.setGravity(Gravity.CENTER_VERTICAL);
        bar.setPadding(dp(ctx, 12), dp(ctx, 6), dp(ctx, 12), dp(ctx, 6));

        GradientDrawable bg = new GradientDrawable();
        bg.setColor(0xFFF7F7F7);
        bg.setCornerRadius(dp(ctx, 2));
        bar.setBackground(bg);

        // 功能按钮 1：快捷填入输入框
        Button b1 = makeButton(ctx, "快捷输入");
        b1.setOnClickListener(v -> setInputText(footer, "这是 Xposed 注入的快捷输入内容"));

        // 功能按钮 2：清空输入框
        Button b2 = makeButton(ctx, "清空");
        b2.setOnClickListener(v -> setInputText(footer, ""));

        // 功能按钮 3：发送（尽力而为，见下方说明）
        Button b3 = makeButton(ctx, "发送");
        b3.setOnClickListener(v -> trySend(footer));

        bar.addView(b1);
        bar.addView(b2);
        bar.addView(b3);
        return bar;
    }

    private Button makeButton(Context ctx, String text) {
        Button btn = new Button(ctx);
        btn.setText(text);
        btn.setTextSize(13);
        btn.setAllCaps(false);
        btn.setTextColor(Color.parseColor("#576B95"));
        btn.setPadding(dp(ctx, 12), dp(ctx, 4), dp(ctx, 12), dp(ctx, 4));
        GradientDrawable bg = new GradientDrawable();
        bg.setColor(Color.WHITE);
        bg.setStroke(1, Color.parseColor("#D5D5D5"));
        bg.setCornerRadius(dp(ctx, 4));
        btn.setBackground(bg);
        LinearLayout.LayoutParams lp = new LinearLayout.LayoutParams(
                ViewGroup.LayoutParams.WRAP_CONTENT, ViewGroup.LayoutParams.WRAP_CONTENT);
        lp.rightMargin = dp(ctx, 8);
        btn.setLayoutParams(lp);
        return btn;
    }

    // ---------- 与输入框交互 ----------

    /** 向微信输入框写文字（利用 ChatFooter 的 j5 字段 = MMEditText） */
    private void setInputText(View footer, String text) {
        try {
            Object editText = XposedHelpers.getObjectField(footer, "j5");
            XposedHelpers.callMethod(editText, "setText", text);
            XposedHelpers.callMethod(editText, "setSelection", text.length());
            // 手动触发 ChatFooter 的文本变化逻辑
            XposedHelpers.callMethod(editText, "requestFocus");
        } catch (Throwable e) {
            toast(footer, "写入输入框失败: " + e.getMessage());
        }
    }

    /**
     * 尽力而为的"发送"：
     * 1) 遍历 footer 子 View 找文字为 "发送"/"Send" 的按钮并点击；
     * 2) 若找不到，说明该版本发送按钮是 ImageButton，退化为只填输入框。
     */
    private void trySend(final View footer) {
        View sendBtn = findButtonByText((ViewGroup) footer, "发送", "Send");
        if (sendBtn != null) {
            footer.post(sendBtn::performClick);
            return;
        }
        toast(footer, "未找到发送按钮（只做了输入框填充）");
    }

    private View findButtonByText(ViewGroup root, String... texts) {
        for (int i = 0; i < root.getChildCount(); i++) {
            View c = root.getChildAt(i);
            if (c instanceof TextView) {
                CharSequence t = ((TextView) c).getText();
                for (String s : texts) {
                    if (!TextUtils.isEmpty(t) && t.toString().trim().equals(s)) return c;
                }
            }
            if (c instanceof ViewGroup) {
                View r = findButtonByText((ViewGroup) c, texts);
                if (r != null) return r;
            }
        }
        return null;
    }

    private void toast(View v, String msg) {
        try {
            Context ctx = v.getContext();
            Toast.makeText(ctx, msg, Toast.LENGTH_SHORT).show();
        } catch (Throwable ignored) { }
    }

    private int dp(Context ctx, float v) {
        return Math.round(ctx.getResources().getDisplayMetrics().density * v);
    }
}
模块配置要点
•  
 assets/xposed_init  里写模块入口类全名（如  com.example.wxhook.WxHook ）；
•  
 AndroidManifest.xml  里声明 Xposed API 版本 + 勾选目标  com.tencent.mm （不要勾"系统框架"）；
•  
编译依赖  XposedBridgeApi （ provided  方式），不要打包进 APK。
四、三条路线的取舍
A（推荐）
 ChatFooter.<init>  +  OnAttachStateChangeListener 
覆盖所有入口（普通聊天/群聊/公众号），不依赖 Fragment 生命周期，防重复天然
需要在 attach 后 post 再操作
B（兜底）
 BaseChattingUIFragment.onResume 
逻辑直观，能拿到 Fragment 上下文
onResume 多次触发需防抖；版本变化时父类名可能变
C（进阶）
 AppPanel （点"+"的面板）
不占用输入框上方空间，样式与微信原生一致
要 hook  AppPanel  内部 GridView/Adapter，改动大、最易被版本更新破坏
如果想做成微信"+"面板里的图标（方案 C），可以继续 hook  com.tencent.mm.pluginsdk.ui.chat.AppPanel （LinearLayout + GridView），找到它的网格容器后把自己的  View  塞进 adapter 数据源，需要时我可以继续帮你分析  AppPanel  的内部 adapter 类。
五、注意事项（防踩坑）
1.  
不要用具体字段名做主要逻辑： ChatFooter  字段全部混淆（ j5 、 g6 …），换版本会变。上面代码只在"填输入框"时用了  j5 ，如果失效，改成运行时在 footer 子树里找  MMEditText  实例（ instanceof MMEditText  或  EditText ）更稳。
2.  
防重复注入：WeakHashMap 以 View 实例为 key，Activity 重建后新 footer 是新对象，不会被误判。
3.  
线程：所有 View 操作都在 UI 线程（构造器/onResume 本身在 UI 线程，post 也保证 UI 线程）。
4.  
作用域： ChatFooter  也被  MassSendMsgUI 、 GameChatRoomUI  等复用，方案 A 会一并注入——如果想只对聊天窗口生效，在  safeInject  里检查  footer.getContext()  是否为  ChattingUI  类型的 Activity 即可。
5.  
Hook 构造器参数个数：现在微信有两个构造器（ (Context, AttributeSet)  与  (Context, AttributeSet, int) ），真正的逻辑在三参那个，Hook 它最全；若新版新增了  (Context)  构造器， findAndHookConstructor  抛异常时方案 B 会自动接管。
