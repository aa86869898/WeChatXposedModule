# 微信好友资料自动同步 — 完整抓取方案

> 朋友改头像/昵称/签名 → 你的微信自动更新 → 如何 Hook 抓取记录

---

## 一、核心原理

**朋友改资料后，你的微信并不是朋友"推送"过来的，而是走以下链路：**

```
服务器 NewSync 通知 "某人资料变更"
        ↓
你的微信 GetContactService 排队拉取
        ↓
CGI: /cgi-bin/micromsg-bin/getcontact
        ↓
processModContact 逐条写入本地 DB
        ↓
头像版本号变了 → 异步下载新头像
```

## 三、np4 (ModContact protobuf) 关键字段

| np4 字段 | 类型 | 含义 | v.b() 中的 setter |
|----------|------|------|------------------|
| `d` | ew5 | **Username** (wxid) | — |
| `e` | ew5 | **NickName（昵称）** | `e0.P1(j1.g(e))` |
| `J` | String | **Alias（微信号）** | `e0.l1(J)` |
| `h` | int | **showHead（头像版本号）** | `e0.d3(h)` |
| `f` | ew5 | **PYInitial（拼音首字母）** | `e0.R1(j1.g(f))` |
| `g` | ew5 | **QuanPin（全拼）** | `e0.S1(j1.g(g))` |
| `v` | ew5 | conRemark（备注） | `e0.F1(j1.g(v))` |
| `s` | int | **BitMask** | `e0.M2(s)` |
| `w` | int | **verifyFlag** | `e0.J2(w)` |
| `B` | int | **deleteFlag** | `e0.X2(B)` |
| `A` | String | **domainList** | `e0.e3(A)` |
| `D` | int | type | `e0.Z1(D)` |
| `E` | String | ticket | `e0.m3(E)` |
| `Z` | String | encryptUsername | `e0.G1(Z)` |
| `Z1` | String | username（明文备用） | — |
| `m` | int | **BitMask** (type 掩码) | — |
| `n` | int | **BitVal** (type 值) | — |
| `e2` | long | **BitMask2** | — |
| `f2` | long | **BitValue2** | — |

> **注意**：头像图片本身不在 np4 中，`np4.h` 只是头像版本号。版本号变了后，微信会异步通过 `modelavatar.g` 重新下载头像图片。但 `np4.h` 的变化就可以作为"头像已更新"的信号。

## 四、完整 BSH 插件代码（可直接在 LSPilot 中使用）

```bsh
// =============================================
// 插件名: ContactSyncLogger
// 功能: 自动抓取好友资料同步（昵称/微信号/头像更新）
// 日志: /sdcard/contact_sync_log.txt
// =============================================

import com.tencent.mm.plugin.messenger.foundation.v;
import a65.np4;
import a65.ew5;
import com.tencent.mm.storage.j4;
import com.tencent.mm.storage.y3;
import java.text.SimpleDateFormat;
import java.util.Date;
import java.io.FileWriter;
import java.io.File;

logFile = "/sdcard/contact_sync_log.txt";

// ========== 工具函数 ==========
formatLog(String tag, String username, String field, String oldVal, String newVal) {
    sdf = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss.SSS");
    time = sdf.format(new Date());
    line = time + " | " + tag + " | " + username + " | " + field 
         + " | old=" + oldVal + " | new=" + newVal;
    log(line);
    try {
        fw = new FileWriter(logFile, true);
        fw.write(line + "\n");
        fw.close();
    } catch (Exception e) {
        log("Write error: " + e.getMessage());
    }
}

// ========== ★ 核心 Hook: processModContact（服务器同步入口） ==========
hookMethodBefore(v.class, "b", param -> {
    np4 mod = (np4) param.args[0];
    
    // 解析字段
    username  = j1.g(mod.d);         // wxid
    nickname  = j1.g(mod.e);         // 昵称
    alias     = mod.J;               // 微信号
    remark    = j1.g(mod.v);         // 备注
    showHead  = mod.h;               // 头像版本号
    type      = mod.m & mod.n;       // 联系人类型
    delFlag   = mod.B;               // 删除标志
    verify    = mod.w;               // 验证标志
    
    fromGetContact = param.args[3].toString();
    scene = param.args[5].toString();

    // 输出日志
    formatLog("[SYNC]", username, "nickname", "?", nickname);
    formatLog("[SYNC]", username, "alias", "?", alias);
    formatLog("[SYNC]", username, "conRemark", "?", remark);
    formatLog("[SYNC]", username, "showHead", "?", "" + showHead);
    formatLog("[SYNC]", username, "type", "?", "" + type);
    formatLog("[SYNC]", username, "delFlag", "?", "" + delFlag);
    formatLog("[SYNC]", username, "verifyFlag", "?", "" + verify);
    formatLog("[SYNC]", username, "fromGetContact", "?", fromGetContact);
    formatLog("[SYNC]", username, "scene", "?", scene);
    formatLog("[SYNC]", username, "---", "---", "---");
});

// ========== 辅助 Hook: GetContactService 入队 ==========
hookMethodBefore(l11.h.class, "a", param -> {
    username = (String) param.args[0];
    chatroom = (String) param.args[1];
    scene    = param.args[2].toString();
    formatLog("[QUEUE]", username, "addToQueue", "chatroom=" + chatroom, "scene=" + scene);
});

// ========== 辅助 Hook: ContactStorage 写入 ==========
hookMethodBefore(j4.class, "l0", param -> {
    contact = (y3) param.args[0];
    formatLog("[DB_SAVE]", contact.d1(), "nickname", "?", contact.M0());
    formatLog("[DB_SAVE]", contact.d1(), "alias", "?", contact.t0());
    formatLog("[DB_SAVE]", contact.d1(), "conRemark", "?", contact.w0());
});

hookMethodBefore(j4.class, "i0", param -> {
    contact = (y3) param.args[0];
    formatLog("[DB_INSERT]", contact.d1(), "nickname", "?", contact.M0());
    formatLog("[DB_INSERT]", contact.d1(), "alias", "?", contact.t0());
});

log("=== ContactSyncLogger 已加载 ===");
log("日志文件: " + logFile);
```

## 七、头像更新的特殊说明

头像更新走**两步**，不是一个方法搞定：

```
第一步: v.b() 中 np4.h (showHead 版本号) 变化
         ↓
第二步: showHead 变了 → modelavatar.g.c() 重新下载头像图片
         ↓
        g.h() 写入本地缓存
```

要完整抓头像更新，需同时 Hook：

| 步骤 | Hook 点 | 作用 |
|------|---------|------|
| 感知头像变更 | `v.b()` → `np4.h` | 版本号对比（变了即新头像） |
| 抓取新头像路径 | `g.c(String username, boolean, boolean)` | 获取下载后的路径 |
| 抓取头像 Bitmap | `g.a(String username)` | 获取实际图片 |
