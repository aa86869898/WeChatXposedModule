wekit 获取微信联系人列表的完整分析
一、整体架构
wekit 是一个 LSPosed/Xposed 模块，通过注入到微信进程内，利用 Hook + 反射机制获取联系人数据。其核心思路是：
微信进程启动 → LSPilot 框架注入 → ContactList 插件加载 → 
DexKit 精确定位微信内部类 → Hook 关键方法 → 拦截/读取联系人数据

三、wekit 最可能采用的三种技术路线
路线 A：Hook 联系人存储读取方法（最直接）
目标：com.tencent.mm.storage.ContactStorage.getAllContacts() 
     或返回 List<Contact> 的类似方法
DexKit 定位方式：
bsh
clazz = findClass()
    .pkg("com.tencent.mm.storage")
    .superClass("java.lang.Object")
    .usingStrings("contact")
    .single()
Hook 方式：
bsh
hookMethodAfter(clazz, "getAllContacts", param -> {
    List contacts = (List) param.getResult();
    // 遍历联系人列表，提取 username, nickname 等
})
路线 B：Hook 联系人数据库查询（底层拦截）
目标：拦截 SQLite 查询 rcontact 表的操作
类名：com.tencent.mm.storagebase 下的数据库访问类
优势：可以获取到最原始、最完整的联系人数据，包括微信可能在前端过滤掉的字段。
路线 C：Hook Contact 类的构造器或 setter（实时捕获）
目标：com.tencent.mm.storage.Contact 的构造函数或关键 setter
当微信从网络同步联系人并创建 Contact 对象时，每个新联系人的创建都会被拦截。
四、ContactList 插件的推断实现方式
结合 wekit 已有的 ContactList 插件（3.9KB），其实现逻辑推断如下：
1. 启动阶段
   ├── DexKit 搜索：findClass().pkg("com.tencent.mm.storage").usingStrings("nickname")
   ├── 定位 Contact 类和 ContactStorage 类
   └── 通过 class_hierarchy 确认继承关系

2. Hook 阶段
   ├── hookMethodAfter(ContactStorage, "getContactList") → 获取全量列表
   ├── hookMethodAfter(Contact, "getUsername") → 记录每个字段访问
   └── 或 hook 数据库 Cursor 的遍历过程

3. 数据导出阶段
   ├── 将联系人数据序列化为 JSON
   ├── 写入文件或通过 Intent 发送
   └── log() 输出到 LSPilot 日志
五、关键技术细节
5.1 如何定位微信内部类（DexKit API）
bsh
// 方法1：按包名+父类找 Contact
contactClass = findClass()
    .pkg("com.tencent.mm.storage")
    .usingStrings("username", "nickname", "alias")
    .single()

// 方法2：按包名+接口找存储类
storageClass = findClass()
    .pkg("com.tencent.mm.model")
    .usingStrings("rcontact", "contact")
    .single()

// 方法3：找返回值为 List<Contact> 的方法
listMethod = findMethod()
    .inClass(storageClass)
    .returnType("java.util.List")
    .single()

// 方式2：反射读取字段
String nickname = (String) getObjectField(contact, "field_nickname");

// 方式3：调用无参方法
Object avatar = callMethod(contact, "getAvatarUrl");
六、总结
wekit 获取微信联系人列表的核心路径：
DexKit 定位 ContactStorage 类 
    → Hook getAllContacts() / getContactList() 方法
        → 拿到 List<Contact> 
            → 反射读取每个 Contact 的 username/nickname/alias 等字段
                → 序列化输出
