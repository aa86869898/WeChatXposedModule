================================================================================
 语音消息发送修复 — 从"卡片XML"变为"语音气泡"
================================================================================

问题: 用 type=34 + X0() 写入普通文本 → 显示为卡片XML消息，不是语音气泡

原因: 语音消息(type=34)的 content 不是普通文字，必须用 u0.c() 生成
      正确的语音 XML，再用 d1() 写入


一、u0.c() — 微信内置的语音XML生成器
================================================================================

  类: u0 (com.tencent.mm.modelvoice 或类似包下的工具类)
  实际包: 需要通过 search_classes 在项目 classLoader 中查找
          → 在 tl.p0.stop() smali 中调用了: u0.c(j.n, j.l, false)
          → 在 y21.x0.t() smali 中也调用了: u0.c(j.n, j.l, false)

  方法签名:
    static String c(String senderName, long durationMs, boolean isSelf)

  参数:
    参数1: senderName → String   发送者昵称/username
    参数2: durationMs → long     语音时长(毫秒)
    参数3: isSelf     → boolean  true=自己发的, false=收到的

  返回: String 语音XML
    格式: "<msg><voicemsg endflag='1' voicelength='5000'
           voiceformat='4' .../></msg>"

  在 y21.x0.t() 中的调用链 (smali已验证):
    d1(u0.c(j.n, j.l, false))
    → d1() 是 setContent(混淆名)


二、d1() — 语音 content setter
================================================================================

  d1(String) → void   设置 field_content (语音专用setter)
  X0(String) → void   设置 field_content (文本专用setter)

  区别: d1() 是撤回提示的setter，在 y21.x0.t() 中复用为语音XML setter
        X0() 是普通文本 content setter


三、正确的语音消息构造 (方式1: 手动构造)
================================================================================

  前提: 获取以下实例
    ClassLoader cl = ...;
    Object msgStorage = getMsgStorage(cl);  // e01.d9.b().u()
    Object u0Class = getU0Class(cl);        // 查找 u0 类

  // 1. 创建消息对象
  Object msg = XposedHelpers.newInstance(
      XposedHelpers.findClass("com.tencent.mm.storage.e9", cl),
      targetTalker);

  // 2. 设置消息类型 = 语音(34)
  XposedHelpers.callMethod(msg, "setType", 34);
  // 或混淆名: XposedHelpers.callMethod(msg, "A1", 34);

  // 3. 生成语音XML content (使用微信内置方法)
  // 格式: u0.c(senderName, durationMs, isSelf)
  String senderName = "我";  // 或自己的wxid
  long duration = 5000;      // 5秒语音
  String voiceXml = (String) XposedHelpers.callStaticMethod(
      u0Class, "c", senderName, duration, false);
  // voiceXml = "<msg><voicemsg endflag='1' voicelength='5000' .../></msg>"

  // 4. 写入语音XML content
  XposedHelpers.callMethod(msg, "d1", voiceXml);

  // 5. 设置语音文件路径
  String voicePath = "/path/to/voice.amr";
  XposedHelpers.callMethod(msg, "j1", voicePath);

  // 6. 设置语音状态
  //   1 = 正常语音
  //   2 = 已发送(对方未播放)  
  //   5 = 已发送(对方已播放)
  XposedHelpers.callMethod(msg, "t1", 1);

  // 7. 设置创建时间
  XposedHelpers.callMethod(msg, "e1", System.currentTimeMillis());

  // 8. 标记为自己发送
  XposedHelpers.callMethod(msg, "k1", 1);

  // 9. 插入DB (自动分配msgId)
  long msgId = (Long) XposedHelpers.callMethod(msgStorage, "H9", msg);

  // 10. 通知UI刷新
  // y21.p0.kj().e() — 刷新语音播放列表(可选)


四、正确的语音消息构造 (方式2: 一行y21.x0.t() — 推荐)
================================================================================

  y21.x0.t(fileName, durationMs, flag, originalMsgInfo) → boolean

  参数:
    参数1: fileName      → String   语音文件完整路径
    参数2: durationMs    → int      语音时长(毫秒)
    参数3: flag          → int      标志(传0)
    参数4: originalMsgInfo → e9     被引用的消息(可传null)

  方法内部:
    ① j(str) 获取 y21.w0 记录
    ② new e9() 创建消息对象
    ③ y1(j.c) 设置 talker
    ④ setType(34) 语音类型
    ⑤ k1(1) 设置某标志
    ⑥ j1(filePath) 设置文件路径
    ⑦ t1(status) 设置状态
    ⑧ d1(u0.c(j.n, j.l, false)) 设置语音XML
    ⑨ e1(createTime) 设置时间
    ⑩ o3(flag) 设置flag
    ⑪ w(j) 写入DB

  Xposed调用:
    Class<?> y21x0 = XposedHelpers.findClass("y21.x0", cl);
    boolean ok = (Boolean) XposedHelpers.callStaticMethod(y21x0, "t",
        voiceFilePath,    // "/sdcard/voice.amr"
        5000,             // 5000ms = 5秒
        0,                // flag
        null              // 无引用消息
    );
    // ok=true → 语音消息气泡已显示在聊天列表中!

六、完整Xposed代码 — 发送语音消息
================================================================================

  /**
   * 发送一条语音消息 (显示为语音气泡)
   * @param cl ClassLoader
   * @param targetTalker 目标会话ID
   * @param voiceFilePath 语音文件完整路径
   * @param durationMs 语音时长(毫秒)
   */
  public static boolean sendVoiceMessage(ClassLoader cl,
      String targetTalker, String voiceFilePath, int durationMs) {

    try {
      // 方式1: 一行搞定 (推荐)
      Class<?> y21x0 = XposedHelpers.findClass("y21.x0", cl);
      boolean ok = (Boolean) XposedHelpers.callStaticMethod(y21x0, "t",
          voiceFilePath, durationMs, 0, null);

      if (ok) {
        XposedBridge.log("[Voice] ✅ 语音消息已发送: " + durationMs + "ms");
      }
      return ok;
    } catch (Throwable e1) {
      // 方式2: 手动构造 (y21.x0找不到时)
      try {
        Object msgStorage = e01.d9.b().u();

        Class<?> e9Class = XposedHelpers.findClass(
            "com.tencent.mm.storage.e9", cl);
        Object msg = XposedHelpers.newInstance(e9Class, targetTalker);

        XposedHelpers.callMethod(msg, "setType", 34);
        XposedHelpers.callMethod(msg, "j1", voiceFilePath);
        XposedHelpers.callMethod(msg, "t1", 1);
        XposedHelpers.callMethod(msg, "e1", System.currentTimeMillis());
        XposedHelpers.callMethod(msg, "k1", 1);

        // 生成语音XML
        String voiceXml = buildVoiceXml(targetTalker, durationMs);
        XposedHelpers.callMethod(msg, "d1", voiceXml);

        long msgId = (Long) XposedHelpers.callMethod(msgStorage, "H9", msg);
        XposedBridge.log("[Voice] ✅ 语音消息已发送 (手动): msgId=" + msgId);
        return true;
      } catch (Throwable e2) {
        XposedBridge.log("[Voice] ❌ 发送失败: " + e2.getMessage());
        return false;
      }
    }
  }

  /**
   * 手动构建语音XML (u0类找不到时的兜底)
   */
  private static String buildVoiceXml(String sender, long durationMs) {
    return "<msg><voicemsg endflag='1' voicelength='" + durationMs
        + "' voiceformat='4' forwardflag='0' fromusername='" + sender
        + "' /></msg>";
  }


七、语音消息正确 vs 错误对比
================================================================================

  错误做法 (显示为卡片XML):
    msg.A1(34);              // 语音类型
    msg.X0("wxid:5000:0");   // ❌ X0是文本setter, 不是语音XML格式

  结果: 消息气泡显示为普通文本 "wxid:5000:0"

  ──────────────────────────────────────────────────────────────

  正确做法 (显示为语音气泡):
    msg.setType(34);                              // 语音类型
    msg.d1(u0.c(sender, 5000L, false));           // ✅ 语音XML
    msg.j1("/voice2/msg_xxx.amr");                // 文件路径
    msg.t1(1);                                    // 状态
    msgStorage.H9(msg);                           // 插入DB

  结果: 消息气泡显示为语音 (带秒数、波形动画)


八、y21.x0.t() 内部完整字段列表 (以防万一需要手动构造)
================================================================================

  1. t1(1)         → field_status = 1 (正常语音)
  2. k1(1)         → field_isSend 的另一个用途 (可能是 isShowTimer)
  3. j1(filePath)  → field_imgPath  (可能)
  4. d1(u0.c(...)) → field_content  ← 这是关键!
  5. e1(createTime)→ field_createTime
  6. o3(flag)      → 某标志字段
  7. y1(talker)    → field_talker
  8. setType(34)   → field_type
  9. a.a.d(msgInfo)→ 可能是版权/权限设置
 10. w(j)          → 最终写DB
