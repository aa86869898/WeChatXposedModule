## B. 代码逐行检查

### B1. `SelfMsgGuard.watermark/hasWatermark`

| 检查点 | 结论 |
|---|---|
| 幂等 | 已带水印直接返回，重复调用内容不变 |
| null / 空串 | 原样返回 |
| @ 单人（`\u2005`） | 插在第一个 `\u2005` 之后，@ 保持首位 |
| @ 单人（普通空格） | 插在第一个空格之后，@ 保持首位 |
| 只有 @ 无正文 | 追加在末尾，@ 仍可高亮 |
| 多人 @ | 只在第一处分隔符后插入一次 |
| 长昵称 | `hasWatermark` 扫描窗口 96 字符，覆盖多人长昵称 |
| 非 @ 内容 | 一律加在最前面 |
