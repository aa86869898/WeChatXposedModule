**版本**：3.0.583（versionCode 30583）

**范围**：消息接收域、自动转发域、点歌域

## 一、结论

| 项 | 内容 |
|---|---|
| 问题 | 分身同步副本 isSend=0，被当成他人消息二次触发 |
| 修复 | `isSelfSender` 按发送者身份判定，三条接收链前置拦截 |
| 白名单 | 四路触发均先过 `inWhitelist`，空白名单不触发 |
| 构建 | assembleRelease 通过 |
| 产物 | 10,489,017 B，MD5 `4e28b987e9c3c86f2d89f3dba78a4e70` |
| 离线验证 | 24/24 |

## 二、消息接收域

判定链：`isSend 读取失败 → 丢弃` → `isSend!=0 → 记录 wxid 并返回` → **`isSelfSender → 返回`** → 水印/自发护栏 → 点歌/AI/播报。

顺序保证：本机发送走 isSend=1；同步副本走身份判定；两者都不会进入业务处理。

## 三、自动转发域

判定顺序：`isSend` → **`isSelfSender`** → 会话 → 来源 → 类型 → msgId → 点歌产物 → 点歌指令 → 自发护栏 → 去重 → 熔断 → 发送。

身份判定放在来源/类型之前，无正文的语音副本也能拦住。

## 四、点歌域

| 组件 | 状态 |
|---|---|
| 触发入口 | MessageHook / MsgReceiveHook / TriggerEngine 三处 |
| 白名单 | 全部在 `maybeHandle` 内硬判定，false 直接返回 |
| 空白名单 | 不触发 |
| 分身重复 | 身份判定前置拦截，账本作为第二道 |

## 五、其余域

其余功能域本轮无改动。
