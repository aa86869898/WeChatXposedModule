# 质检修复报告 v3.0.551

## 一、防撤回系统提示仍不显示（根因修复）

### 现象
v3.0.550 日志显示 `[H1] hint inserted talker=wxid_... id=-1`——id=-1 说明 MsgInfoStorage.Nb 入库失败，用户看不到提示。

### 根因（双 Agent 审查确认）
1. **手动构造的 e9 消息 talker 为空**：`u1(talker)` setter 在当前微信版本（8.0.79）下静默失败，
   `Nb` 入口校验 `y8.J0(N0())`（talker 为空）直接返回 -1。
2. **read-back 只验证 type**：未验证 talker/isSend，掩盖了真正失败原因。
3. **setter 静默吞异常**：callSafe 无日志，失败无感知。

### 修复内容
1. **带参构造 e9**：`XposedHelpers.newInstance(e9, talker)`（GroupFeatures 实证路径），
   失败才回退无参构造 + u1。
2. **完整 read-back 验证**：入库前验证 `getType()==10000`、`N0()`（talker）== 传入 talker、
   `z0()`（isSend）== 0，任一失败则放弃入库，不产生脏消息。
3. **setter 失败记录日志**：callSafe 不再静默吞异常，关键 setter 失败会在日志输出。
4. **去掉无意义 Mb 兜底**：避免重复失败触发。
5. **ClassLoader 统一**：优先使用 Tinker 真实运行 CL（与 WeChatMessenger 一致）。
6. 补充 status=1 字段（微信入库必需）。

## 二、群管理功能修复

1. **黑白名单显示成员列表**：配置行的 summary 改为「黑名单（已选 N 人）：昵称1、昵称2…」（最多 4 个，超出显示共 N 人）。
2. **窗口 90% 限制**：
   - 配置弹窗：宽度 90% 屏、高度 = min(内容+按钮, 90% 屏)，内容区滚动、底部按钮固定。
   - 群成员选择器：窗口固定 ≤90% 宽高，并扣减导航栏高度避免底部按钮被遮挡。
3. **窗口按钮排列修复**：保存/取消按钮从滚动区移到窗口底部固定，不再随内容滚走。
4. **全局设置提示**：无群聊上下文时选择成员会提示「全局设置请在具体群聊内选择成员」。
5. **名单顺序稳定**：名单集合改用 LinkedHashSet，成员显示顺序不再跳动。

## 三、审查结论
- 提示行入库路径与微信真实运行 CL 一致，带参构造 + read-back 三重验证，不再产生 id=-1 脏消息。
- 群管理所有窗口宽高均 ≤ 屏幕 90%，按钮固定底部，黑白名单显示成员昵称。
- 编译：通过（assembleRelease）。
