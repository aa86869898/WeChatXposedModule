# 全项目功能审查报告 · v3.0.584

**版本**：3.0.584（versionCode 30584）
**本轮重点**：msgsource 占位回调不进业务
**范围**：消息接收域、自动转发域、点歌域

## 一、结论

| 项 | 内容 |
|---|---|
| 现象 | 点歌后 545 个群收到 msgsource XML |
| 根因 | 首次落库回调正文未回填，护栏看到的是 XML |
| 修复 | 三条接收链在占位回调直接跳过，不占去重键 |
| 构建 | assembleRelease 通过 |
| 产物 | 10,489,010 B，MD5 `78d3c0e99b1cbe16684eb3cee3de0587` |
| 离线验证 | 34/34 |

## 二、消息接收域

判定链：`isSend 读取失败 → 丢弃` → `isSend!=0 → 返回` → **`msgsource 占位 → 返回`** → `isSelfSender → 返回` → 水印/自发护栏 → 业务。

占位判定最先执行，保证后续所有规则看到的是真实正文。

## 三、自动转发域

判定顺序：`isSend` → `isSelfSender` → 会话 → 来源 → 类型 → **`msgsource 占位`** → msgId → 点歌产物/指令 → 自发护栏 → 去重 → 熔断 → 发送。

占位判断在去重之前，第二次回调不会被第一次拦掉。

## 四、点歌域

| 组件 | 状态 |
|---|---|
| 指令识别 | 不受影响，正文回调才匹配 |
| 产物账本 | 不受影响，占位回调不登记 |
| 白名单 | 不变，仍在 `maybeHandle` 前置 |
| 自身发送识别 | 保留自 v3.0.583 |
