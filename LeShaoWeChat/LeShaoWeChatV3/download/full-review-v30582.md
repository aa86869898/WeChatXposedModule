## 三、自动转发域

判定顺序：`isSend` → 会话 → 来源 → 类型 → msgId → **点歌产物** → **点歌指令** → 自发护栏 → 去重 → 熔断 → 发送。

点歌两条判定位于自发护栏之前，属于业务硬规则，不依赖水印是否命中。
