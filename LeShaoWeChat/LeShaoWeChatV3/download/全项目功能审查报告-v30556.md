# 全项目功能审查报告 v3.0.556

## 审查范围
- TTS #tts 未发送就切换开关
- TTS 无限循环 / 合成内容不完整 / 乱发给别人

## 结论
根因是 ChatFooter 拦截器误 hook 了 8.0.79 中返回 void 的「输入框内容同步回调」，
打字时即触发 #tts toggle 和 TTS 模式转语音，导致：
- #tts 未发送就切换
- 输入框每字符逐步合成乱发（"大家好"只打 3 字就被发出去）
- 语音消息发送后反复触发合成（无限循环）

修复：只 hook 返回 boolean 的真发送方法（p/g/Q0），输入框打字不再触发，按发送才处理。
