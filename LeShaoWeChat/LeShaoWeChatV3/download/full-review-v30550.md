# 全项目功能审查报告 v3.0.550

## 审查范围
- 防撤回系统提示修复（用户反馈「别人撤回没有提示」）
- 群管理页面 UI 优化（背景/间距/窗口自适配/成员选择器）

## 结论

### 防撤回
1. **提示不显示的根因**：v3.0.549 setter 检查用 getDeclaredMethods 查不到父类 setter，误判放弃插入。
   已改为直接调用（callMethod 遍历父类）+ 入库前 getType()==10000 read-back 验证。
2. **自定义提示文字**：配置弹窗新增输入框，{name} 自动替换发送者昵称，留空用默认文案。
3. **安全**：type 验证失败即放弃入库，不产生脏消息。

### 群管理
1. **不透明背景**：窗口背景 surface 实底，不再透明。
2. **间距优化**：各区块上下间距压缩，页面更紧凑。
3. **窗口自适配**：宽 90%、高上限 90%、内容滚动，与其他功能弹窗规范一致。
4. **群成员选择器**：联系人选择器同款样式（头像 + 昵称/备注 + 搜索 + 多选），
   数据来自群成员 wxid + rcontact 昵称查询。
