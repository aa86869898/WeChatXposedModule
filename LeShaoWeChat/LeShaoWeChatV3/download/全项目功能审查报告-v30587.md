| 回归 | 新增 14 项、旧 15 项全通过 |

## 二、判定链现状

| 环节 | 条件 | 留痕 |
|---|---|---|
| 总开关 | `sEnabled` | 未开启 |
| isSend | 读取失败 / 非 0 | 对应原因 |
| 自身判定 | 发送者是自己 | 同步副本 |
| 会话 | 空 talker | talker 为空 |
| 来源 | 不在 `sSources` | 来源不匹配 + 已选数量 |
| 类型 | 不在 `sTypes` | 类型 + 已选类型 |
| 占位 | `<msgsource>` 前缀 | 正文尚未回填 |
| 自发 | msgId 台账 / 内容水印 | 对应原因 |
| 点歌 | 指令 / 产物 | 对应原因 |
| 去重 | svrId 或内容键 | 重复消息 |
| 熔断 | 连续失败 | 熔断目标数 |
| 成功 | 进入 `forwardAll` | 已转发 -> N 个目标 |

## 三、设计取舍

- 判定结论存放在内存，进程重启归零为「尚未收到消息」，不落盘、不占存储；
- 群聊来源不匹配限频，避免 500 个群的闲聊把日志刷满；
- 私聊逐条记录，复测来源配置时信息最全。
