# 质检修复报告 v3.0.562

## 红包 TTS 语音回复独立回复语设置

### 需求
用户反馈：TTS 语音回复没有设置回复语功能。

### 实现
1. **TTS 语音回复行新增「[设置]」入口（开关左侧）**：点击打开「红包TTS语音回复语」设置子页（pageId 39）。
2. **TTS 专属回复语表格**：与文字回复语**分开存储**（`ls_redpacket_auto_reply_tts_texts`），表格式勾选（CheckBox），支持添加/删除。
3. **抢到红包自动随机转语音**：TTS 开关开启时，从 **TTS 勾选**的回复语中随机抽一条，调用 TTS 合成发送语音消息；合成失败回退文本。
4. 文字自动回复保持原有逻辑（`ls_redpacket_auto_reply_texts`），两者互不影响。

### 配置入口
模块主页 → 红包转账：
- 「自动回复」行 [设置] → 文字回复语表格（pageId 38）
- 「TTS 语音回复」行 [设置] → TTS 专属回复语表格（pageId 39）
