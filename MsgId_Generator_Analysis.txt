二、msgId 生成器 (uh3.k0.b)
================================================================================

  类: uh3.k0 — 每张消息表一个实例
  字段:
    this.a    → long      当前序列号 (auto-increment)
    this.b[]  → uh3.j0[]  保留区间数组 (跳过)
    this.d    → String    表名 ("message")

  方法: synchronized void b(e9 msgInfo)
    ① j = this.a
    ② 如果 j 命中保留区间的末尾 → 跳到下一个区间的开头
    ③ 否则 this.a = j + 1
    ④ msgInfo.setMsgId(this.a)   ← 赋值!
    ⑤ e.putLong("msg." + this.d, this.a)  ← 持久化

  方法: boolean c(long msgId)
    检查 msgId 是否在保留区间内

  构造: uh3.k0(int, String, uh3.j0[])
    j0: 包含 long a(区间开始) 和 long b(区间结束)
    保留区间是跳过的ID段, 正常消息不占用这些ID
