 u0 类 — 完整路径和签名 (从 y21.x0.r() Smali 提取)
================================================================================

Smali 确认:

  接口:   qh3.u0  (服务接口)
  实现:   h90.b   (实际实现类)
  获取:   n0.c(qh3.u0.class) → h90.b 实例


方法签名:
================================================================================

  Mj(lin5.y, String srcFileName, boolean isCreate) → String
    作用: 获取源文件完整路径
    参数1: lin5.y  → 静态字段 y.j (sget-object Lin5/y;->j:Lin5/y)
    参数2: srcFileName → 源文件名或路径
    参数3: isCreate    → false=不创建目录
    返回: 文件完整路径

  Nj(lin5.y, String dstFileName, boolean isCreate, boolean flag) → String
    作用: 获取目标文件完整路径(voice2目录)
    参数1: lin5.y  → 静态字段 y.j
    参数2: dstFileName → 目标文件名
    参数3: isCreate    → false
    参数4: flag        → true
    返回: 目标文件完整路径


r() 内部完整流程:
================================================================================

  y21.x0.r(talker, srcPath, duration):

  ① g(talker, prefix) → newFileName
     "amr_xxxxx"

  ② n0.c(qh3.u0.class) → h90.b
     b.Mj(y.j, srcPath, false) → srcFullPath
     b.Nj(y.j, newFileName, false, true) → dstFullPath

  ③ w6.d(srcFullPath, dstFullPath, false) → long
     copyFile

  ④ t(newFileName, duration, 1, null) → boolean
     创建 e9(type=34) + 写 DB + 通知

  long result = (Long) XposedHelpers.callStaticMethod(w6, "d", srcFull, dstFull, false);

  // Step 4: 写 DB
  boolean ok = (Boolean) XposedHelpers.callStaticMethod(y21x0, "t", newName, duration, 0, null);
