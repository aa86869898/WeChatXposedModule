# 微信「聊天窗口长按消息 → 转发/多选 → 左下角入口 → 原生联系人选择器」替换方案

> 逆向样本：`com.tencent.mm`（微信，含 MVVM 新版转发页 + 旧版 SelectContactUI 双实现并存）
> 目标：把该入口拉起的**微信原生联系人选择器**替换为**你自己模块里的联系人选择器**，并保证后续微信原生转发逻辑 100% 继续跑通。
> 本文只给业务代码（Java + Xposed Hook），不含 compileSdk / build.gradle / AGP 配置。

## 3. Hook 方案设计（4 套 + 选型）

### 3.1 方案 A（★ 推荐）：宿主 Activity 内容替换，结果走原生机制

**做法**
1. hook `com.tencent.mm.ui.mvvm.MvvmContactListUI#onCreate(Bundle)`（**after**，不阻止 super，避免 VASActivity 状态机崩）
2. 校验 `activity.getIntent()` 的转发选择器指纹（`list_type ∈ {5,14}` + `titile` + 关键 extras）
3. 把自己选择器的全屏 View `addView` 到 `activity.getWindow().getDecorView()`（盖住原生 UI），原生返回键/标题被盖住，用我们自己的返回按钮
4. 用户在我们 UI 里选完 → `activity.setResult(-1, data)` + `activity.finish()`
5. 微信真实机制把结果分发给 `SelectConversationUI.onActivityResult(rc, -1, data)` → 后续 100% 原生

**优点**：requestCode / resultCode / Intent / onActivityResult 分发 / Fragment 分发全部走微信真实通道，**不伪造任何回调**；不需要把 Activity 写进微信 Manifest；不引入跨进程/跨 Task 问题；不依赖混淆方法名。
**缺点**：多实例化一次原生 Activity（开销小，可忽略）。

### 3.2 方案 B：intent 层硬拦截（不启动原生页面）

hook `androidx.fragment.app.FragmentActivity#startActivityForResult(Intent,int)`（+`Activity` 版、+`Instrumentation#execStartActivity` 兜底），命中转发选择器 intent 后 `param.setResult(null)` 阻止启动，自己弹进程内浮层；确认时反射调用 `caller.onActivityResult(rc, -1, data)`。
**优点**：真正的"不出现原生页面"。
**缺点**：伪造回调（绕过了 `ActivityThread` 的真实分发；`FragmentActivity` 的 `mFragments.noteStateNotSaved()` 等被跳过），极端情况下有 `onSaveInstanceState` 时序问题。适合作为"用户显式开启的彻底替换模式"。

### 3.3 方案 C：外部 Activity（你自己模块的 Activity）

在你的模块 Manifest 里声明 `exported=true` + `launchMode=standard` + `theme` 透明 + `taskAffinity=""`，拦截 intent 后改写 ComponentName 指向你的 Activity，仍用原 requestCode。
**缺点**：跨 App 的 `startActivityForResult` 结果回传依赖 Task 亲和性，微信这种多 Task/`VASActivity` 场景下不稳定，**不建议作为首选**。

### 3.4 方案 D：只换数据源，不换 UI

保留原生 `WxRecyclerView` + 原生 item + 原生 ActionBar 确定按钮，只把 Adapter 的数据集换成你的（白名单过滤/自有列表）。
**优点**：最省事，UI 完全原生；**缺点**：外观不是你的。

### 3.5 选型建议

- 默认 **A**（稳）。
- 给用户一个开关：A（覆盖原生页面）/ B（彻底不启动原生页面）/ D（只换数据）。三者共用同一套 `OwnPickerView`、`ContactSource`、`ResultContract`。

```java
    public static boolean isForwardSelector(Intent it) {

        Bundle b = it.getExtras();

            return false;

        if (it.getBooleanExtra("recommend_chatroom", false))      return true;   // b0.invoke 单选
        if (it.getBooleanExtra("group_select_need_result", false))return true;   // b0.invoke / GroupCard
        if (it.hasExtra("already_select_contact"))                return true;   // U7 / 多选
        if (it.hasExtra("Select_Conv_Type"))                      return true;   // T7 分流
        if (lt == 14 && it.hasExtra("max_limit_num"))             return true;   // 多选
        if (it.hasExtra("block_contact") && it.hasExtra("list_attr")) return true; // 兜底

        if (Cfg.verboseTrace) Logx.i("reject(no forward feature) " + desc(it));
        return false;
    }

    /** 是否"发起群聊"链（MMCreateChatroomUI 等），默认不接管 */
    public static boolean isCreateChatroomChain(Intent it) {
        if (!Cfg.hookCreateChatroomChain) return false;
        if (it == null) return false;
        return it.hasExtra("scene") && it.hasExtra("query_phrase_list");
    }

    public static boolean isMulti(Intent it) {
        if (it == null) return false;
        if (it.getIntExtra("list_type", -1) == 14) return true;
        if (it.hasExtra("already_select_contact")) return true;
        return false;
    }

    public static String desc(Intent it) {
        if (it == null) return "null";
        StringBuilder sb = new StringBuilder();
        sb.append("comp=").append(it.getComponent() == null ? "-" : it.getComponent().getClassName());
        Bundle b = it.getExtras();
        if (b != null) for (String k : b.keySet()) {
            Object v = b.get(k);
            sb.append(" | ").append(k).append('=').append(v == null ? "null" : v.toString());
        }
        return sb.toString();

        String extra = Cfg.extraBlock;
        if (!extra.isEmpty()) for (String x : extra.split(",")) if (!x.isEmpty()) out.add(x.trim());
```

```java
package com.your.module.wxforward;

import android.app.Activity;
import android.content.Context;
import android.content.Intent;

import org.json.JSONArray;
import org.json.JSONObject;

import java.io.File;
import java.io.FileInputStream;

import java.util.Collections;
import java.util.HashSet;
import java.util.List;
import java.util.Set;

public final class ContactSources {

    private ContactSources() {}

    public static ContactSource pick() {
        Cfg.init();
        if ("module".equals(Cfg.source)) return new ModuleSource();
        if ("mirror_then_module".equals(Cfg.source)) return new MirrorThenModule();
        return new NativeMirrorSource();
    }

    /* ---------- 1. 原生镜像：从被覆盖的原生列表里拿同一份数据 ---------- */
    public static final class NativeMirrorSource implements ContactSource {
        public String name() { return "mirror"; }
        public boolean supports(String m) { return true; }
        public List<ContactItem> load(Context ctx, Intent sel) {
            List<ContactItem> raw = new ArrayList<>();
            if (ctx instanceof Activity) raw.addAll(NativeMirror.read((Activity) ctx));
            if (raw.isEmpty()) Logx.w("mirror: empty, fallback to module source");
            return raw;
        }
    }

    /* ---------- 2. 自有数据源（示例：模块 files 目录 contacts.json） ---------- */
    public static final class ModuleSource implements ContactSource {
        public String name() { return "module"; }
        public boolean supports(String m) { return true; }
        public List<ContactItem> load(Context ctx, Intent sel) throws Exception {
            List<ContactItem> out = new ArrayList<>();
            File f = new File(ctx.getFilesDir(), Cfg.sourceFile);
            if (!f.exists()) { Logx.w("module source file missing: " + f); return out; }
            FileInputStream fis = new FileInputStream(f);
            byte[] buf = new byte[(int) f.length()];
            int n = fis.read(buf); fis.close();
            if (n <= 0) return out;
            JSONArray arr = new JSONArray(new String(buf, 0, n, "UTF-8"));
            for (int i = 0; i < arr.length(); i++) {
                JSONObject o = arr.getJSONObject(i);
                out.add(new ContactItem(o.optString("username"), o.optString("nickname"), o.optInt("type", 0)));
            }
            return out;
        }
    }

    /* ---------- 3. 先镜像、失败再自有 ---------- */
    public static final class MirrorThenModule implements ContactSource {
        public String name() { return "mirror_then_module"; }
        public boolean supports(String m) { return true; }
        public List<ContactItem> load(Context ctx, Intent sel) throws Exception {
            List<ContactItem> a = new NativeMirrorSource().load(ctx, sel);
            if (!a.isEmpty()) return a;
            return new ModuleSource().load(ctx, sel);
        }
    }

    /* ---------- 过滤：block_contact + 无效项 ---------- */
    public static List<ContactItem> filter(Intent sel, List<ContactItem> in) {
        Set<String> block = SelectorSignature.blockContacts(sel);
        List<ContactItem> out = new ArrayList<>();
        for (ContactItem c : in) {
            if (c == null || c.username == null || c.username.isEmpty()) continue;
            if (c.username.equals("weixin")) continue;               // 微信团队/文件传输
            if (block.contains(c.username)) continue;
            out.add(c);
        }
        Collections.sort(out, (x, y) -> {
            int a = x.isRoom() ? 1 : 0, b = y.isRoom() ? 1 : 0;
            return a != b ? a - b : String.CASE_INSENSITIVE_ORDER.compare(
                    x.nickname == null ? "" : x.nickname, y.nickname == null ? "" : y.nickname);
        });
        return out;
    }
}
```

```java
import java.util.ArrayList;
import java.util.List;
import java.util.WeakHashMap;

public final class OwnPickerController {

    public enum Deliver { NATIVE_SETRESULT, FAKE_ON_ACTIVITY_RESULT }

    static final class Session {
        Activity drawOn;        // 我们在谁身上画 UI
        Activity resultTarget;  // 谁期待结果
        Intent src;
        int requestCode = -1;
        OwnPickerView view;
        Deliver deliver;
        long ts = System.currentTimeMillis();
        boolean done;
    }

    private static final WeakHashMap<Activity, Session> S = new WeakHashMap<>();
    private static final Object LOCK = new Object();

    /* ================= 主入口 ================= */

    /** 方案 A / 方案 D：宿主就是原生选择器 Activity */
    public static void attachOnSelector(Activity selector, Intent src) {
        attach(selector, selector, src, -1, Deliver.NATIVE_SETRESULT);
    }

    /** 方案 B：宿主是转发页（调用方），我们自己伪造 onActivityResult */
    public static void attachOnCaller(Activity caller, Intent src, int requestCode) {
        attach(caller, caller, src, requestCode, Deliver.FAKE_ON_ACTIVITY_RESULT);
    }

    private static void attach(Activity drawOn, Activity resultTarget, Intent src,
                               int requestCode, Deliver deliver) {
        final String key = "WxFwdSel";
        Session old = S.get(drawOn);
        if (old != null) { Logx.i("replace existing session on " + drawOn.getClass().getName()); }

        List<ContactItem> data = new ArrayList<>();
        try {
            ContactSource s = ContactSources.pick();
            Logx.i("load source=" + s.name());
            data = ContactSources.filter(src, s.load(drawOn, src));
            Logx.i("data size=" + data.size());
        } catch (Throwable t) {
            Logx.e("contact source failed", t);
            toast(drawOn, "联系人加载失败");
        }

        boolean multi = SelectorSignature.isMulti(src);
        int max = src == null ? Cfg.defaultMaxSelect : src.getIntExtra("max_limit_num", Cfg.defaultMaxSelect);

        OwnPickerView v = OwnPickerView.create(drawOn, src, data, multi, max, new OwnPickerView.Callback() {
            @Override public void onConfirm(List<ContactItem> sel) {
                Session s2 = S.get(drawOn);
                if (s2 == null || s2.done) return;
                s2.done = true;
                List<String> users = new ArrayList<>();
                for (ContactItem c : sel) users.add(c.username);
                Logx.i("confirm users=" + users);
                deliverResult(s2, users);
            }
            @Override public void onCancel() {
                Session s2 = S.get(drawOn);
                if (s2 == null || s2.done) return;
                s2.done = true;
                Logx.i("cancel");
                deliverCancel(s2);
            }
        });

        Session s = new Session();
        s.drawOn = drawOn; s.resultTarget = resultTarget; s.src = src;
        s.requestCode = requestCode; s.view = v; s.deliver = deliver;

        try {
            ViewGroup decor = (ViewGroup) drawOn.getWindow().getDecorView();
            FrameLayout.LayoutParams lp = new FrameLayout.LayoutParams(
                    ViewGroup.LayoutParams.MATCH_PARENT, ViewGroup.LayoutParams.MATCH_PARENT);
            decor.addView(v.view(), lp);
            Logx.i("overlay attached to " + drawOn.getClass().getName());
        } catch (Throwable t) {
            Logx.e("decor addView failed", t);
            return;
        }
        synchronized (LOCK) { S.put(drawOn, s); }
    }

    /* ================= 结果分发 ================= */

    private static void deliverResult(Session s, List<String> users) {
        Intent data = ResultContract.build(s.src, users);
        try {
            if (s.deliver == Deliver.NATIVE_SETRESULT) {
                // ★ 走微信真实机制：setResult + finish → ActivityThread  → onActivityResult
                s.resultTarget.setResult(Activity.RESULT_OK, data);
            } else {
                s.resultTarget.setResult(Activity.RESULT_OK, data);
                callOnActivityResult(s.resultTarget, s.requestCode, Activity.RESULT_OK, data);
            }
        } catch (Throwable t) {
            Logx.e("deliverResult failed", t);
        } finally {
            teardownAndFinish(s);
        }
    }

    private static void deliverCancel(Session s) {
        try {
            s.resultTarget.setResult(Activity.RESULT_CANCELED, null);
            if (s.deliver == Deliver.FAKE_ON_ACTIVITY_RESULT) {
                callOnActivityResult(s.resultTarget, s.requestCode, Activity.RESULT_CANCELED, null);
            }
        } catch (Throwable t) {
            Logx.e("deliverCancel failed", t);
        } finally {
            teardownAndFinish(s);
        }
    }

    private static void teardownAndFinish(Session s) {
        detach(s);
        try { s.resultTarget.finish(); } catch (Throwable t) { Logx.e("finish failed", t); }
    }

    /** 反射调用 Activity#onActivityResult(int,int,Intent)（方案 B 专用） */
    private static void callOnActivityResult(Activity a, int req, int res, Intent data) {
        try {
            Method m = findOnActivityResult(a.getClass());
            if (m == null) { Logx.w("onActivityResult not found on " + a.getClass()); return; }
            m.setAccessible(true);
            m.invoke(a, req, res, data);
        } catch (Throwable t) {
            Logx.e("callOnActivityResult failed", t);
        }
    }
    private static Method findOnActivityResult(Class<?> c) {
        for (Class<?> k = c; k != null; k = k.getSuperclass()) {
            try { return k.getDeclaredMethod("onActivityResult", int.class, int.class, Intent.class); }
            catch (NoSuchMethodException ignore) { }
        }
        return null;
    }

    /* ================= 生命周期 ================= */

    public static void onHostResumed(Activity a) {
        Session s = S.get(a);
        if (s == null) return;
        try { s.view.view().bringToFront(); } catch (Throwable ignore) { }
    }

    public static boolean onHostBackPressed(Activity a) {
        Session s = S.get(a);
        if (s == null || s.done) return false;
        return s.view.onBackPressed();
    }

    public static void onHostPaused(Activity a) { /* no-op */ }

    public static void detach(Session s) {
        if (s == null) return;
        try {
            View v = s.view.view();
            if (v != null && v.getParent() instanceof ViewGroup) {
                ((ViewGroup) v.getParent()).removeView(v);
            }
            s.view.recycle();
        } catch (Throwable ignore) { }
        synchronized (LOCK) { S.remove(s.drawOn); }
    }

    public static void installLifecycle(ClassLoader cl) {
        try {
            de.robv.android.xposed.XposedHelpers.findAndHookMethod("android.app.Activity", cl,
                    "onResume", new de.robv.android.xposed.XC_MethodHook() {
                        @Override protected void afterHookedMethod(MethodHookParam p) {
                            onHostResumed((Activity) p.thisObject);
                        }
                    });
        } catch (Throwable t) { Logx.e("hook onResume failed", t); }

        try {
            de.robv.android.xposed.XposedHelpers.findAndHookMethod("android.app.Activity", cl,
                    "onBackPressed", new de.robv.android.xposed.XC_MethodHook() {
                        @Override protected void beforeHookedMethod(MethodHookParam p) {
                            Activity a = (Activity) p.thisObject;
                            if (onHostBackPressed(a)) p.setResult(null);
                        }
                    });
        } catch (Throwable t) { Logx.e("hook onBackPressed failed", t); }

        try {
            de.robv.android.xposed.XposedHelpers.findAndHookMethod("android.app.Activity", cl,
                    "onDestroy", new de.robv.android.xposed.XC_MethodHook() {
                        @Override protected void afterHookedMethod(MethodHookParam p) {
                            Session s = S.remove(p.thisObject);
                            if (s != null) detach(s);
                        }
                    });
        } catch (Throwable t) { Logx.e("hook onDestroy failed", t); }
    }

    private static void toast(Activity a, String s) {
        try { android.widget.Toast.makeText(a, s, android.widget.Toast.LENGTH_SHORT).show(); }
        catch (Throwable ignore) { }
    }
}
```

### 4.10 `ParentChainInterceptor.java`（★ 核心：按父类链自动识别，免关心类名）

```java
package com.your.module.wxforward;

import android.app.Activity;
import android.content.Intent;

import java.util.Arrays;

import java.util.HashSet;
import java.util.Set;

/**
 * 微信换了多少名字都无所谓：
 *   - 不依赖 MvvmContactListUI / SelectContactUI 的具体类名
 *   - 只依赖两个"血缘锚点" + 转发意图指纹
 * 血缘锚点在本样本中已验证：
 *   com.tencent.mm.ui.mvvm.MvvmContactListUI -> com.tencent.mm.plugin.mvvmlist.BaseMvvmListActivity
 *   com.tencent.mm.ui.contact.SelectContactUI -> com.tencent.mm.ui.contact.MMBaseSelectContactUI
 */
public final class ParentChainInterceptor {

    public static final Set<String> ANCHORS = new HashSet<>(Arrays.asList(
            "com.tencent.mm.plugin.mvvmlist.BaseMvvmListActivity",
            "com.tencent.mm.ui.contact.MMBaseSelectContactUI"));

    private ParentChainInterceptor() {}

    public static void install(ClassLoader cl) {
        try {
            de.robv.android.xposed.XposedHelpers.findAndHookMethod("android.app.Activity", cl,
                    "onCreate", android.os.Bundle.class,
                    new de.robv.android.xposed.XC_MethodHook() {
                        @Override protected void afterHookedMethod(MethodHookParam p) {
                            Activity a = (Activity) p.thisObject;
                            try { inspect(a); } catch (Throwable t) { Logx.e("inspect failed", t); }
                        }
                    });
            Logx.i("ParentChainInterceptor installed");
        } catch (Throwable t) { Logx.e("install ParentChainInterceptor failed", t); }
    }

    public static void inspect(Activity a) {
        if (a == null || a.isFinishing()) return;
        Intent it = a.getIntent();
        if (it == null) return;
        // 先做最便宜的判断：意图指纹
        if (!SelectorSignature.isForwardSelector(it)) return;
        if (!chainHit(a.getClass())) {
            Logx.w("sig hit but chain miss: " + a.getClass().getName() + " :: " + SelectorSignature.desc(it));
            return;
        }
        Logx.i("HIT " + a.getClass().getName() + " mode=" + Cfg.mode + " :: " + SelectorSignature.desc(it));
        if (Cfg.mode == 0)  OwnPickerController.attachOnSelector(a, it);
        if (Cfg.mode == 2) { NativeAdapterSwap.apply(a, it); return; }
    }

    public static boolean chainHit(Class<?> c) {
        for (Class<?> k = c; k != null; k = k.getSuperclass()) {
            if (ANCHORS.contains(k.getName())) return true;
        }
        return false;
    }
}
```

### 4.11 `FwdSelectorHookB.java`（方案 B：intent 层硬拦截）

```java
package com.your.module.wxforward;

import android.app.Activity;
import android.app.Instrumentation;
import android.content.Context;
import android.content.IBinder;
import android.content.Intent;
import android.os.Bundle;

import java.lang.reflect.Method;
import java.util.Arrays;

public final class FwdSelectorHookB {

    private static final ThreadLocal<Intent> INFLIGHT = new ThreadLocal<>();

    public static void install(ClassLoader cl) {
        // 1) FragmentActivity 的 2 参 / 3 参版本（微信 Activity 基本都继承它）
        try {
            de.robv.android.xposed.XposedHelpers.findAndHookMethod(
                    "androidx.fragment.app.FragmentActivity", cl,
                    "startActivityForResult", Intent.class, int.class,
                    new de.robv.android.xposed.XC_MethodHook() {
                        @Override protected void beforeHookedMethod(MethodHookParam p) {
                            handle((Activity) p.thisObject, (Intent) p.args[0], (Integer) p.args[1], p);
                        }
                    });
        } catch (Throwable t) { Logx.w("no FA#safr(Intent,int): " + t); }

        try {
            de.robv.android.xposed.XposedHelpers.findAndHookMethod(
                    "androidx.fragment.app.FragmentActivity", cl,
                    "startActivityForResult", Intent.class, int.class, Bundle.class,
                    new de.robv.android.xposed.XC_MethodHook() {
                        @Override protected void beforeHookedMethod(MethodHookParam p) {
                            handle((Activity) p.thisObject, (Intent) p.args[0], (Integer) p.args[1], p);
                        }
                    });
        } catch (Throwable t) { Logx.w("no FA#safr(Intent,int,Bundle): " + t); }

        // 2) 原生 Activity 版本（兜底；若上面已命中，本 hook 因 INFLIGHT 去重不会重复处理）
        try {
            de.robv.android.xposed.XposedHelpers.findAndHookMethod(
                    "android.app.Activity", cl,
                    "startActivityForResult", Intent.class, int.class,
                    new de.robv.android.xposed.XC_MethodHook() {
                        @Override protected void beforeHookedMethod(MethodHookParam p) {
                            handle((Activity) p.thisObject, (Intent) p.args[0], (Integer) p.args[1], p);
                        }
                    });
        } catch (Throwable t) { Logx.e("hook Activity#safr failed", t); }

        // 3) 最终兜底：Instrumentation.execStartActivity（捕获一切显式启动）
        installInstrumentation(cl);
    }

    /**
     * 最终兜底：Instrumentation.execStartActivity。
     * 不写死签名——按方法名枚举 Instrumentation 的所有重载，逐个 hook，
     * 这样 Android 8~15 的签名漂移（多一个 user/token 参数之类）都不用改代码。
     */
    private static void installInstrumentation(ClassLoader cl) {
        Class<?> ins;
        try { ins = cl.loadClass(Instrumentation.class.getName()); } catch (Throwable t) { return; }
        for (Method m : ins.getDeclaredMethods()) {
            if (!"execStartActivity".equals(m.getName())) continue;
            final Class<?>[] pts = m.getParameterTypes();
            try {
                de.robv.android.xposed.XposedHelpers.findAndHookMethod(ins, "execStartActivity", (Object[]) pts,
                        new de.robv.android.xposed.XC_MethodHook() {
                            @Override protected void beforeHookedMethod(MethodHookParam p) {
                                Object[] a = p.args;
                                Intent it = null;
                                int rc = -1;
                                Object token = null;
                                Object ctxObj = null;
                                for (int i = 0; i < a.length; i++) {
                                    if (a[i] instanceof Intent) it = (Intent) a[i];
                                    else if (a[i] instanceof IBinder && token == null) token = a[i];
                                    else if (a[i] instanceof Context) ctxObj = a[i];
                                    else if (a[i] instanceof Integer && rc == -1
                                             && pts[i] == int.class) rc = (Integer) a[i];
                                }
                                if (it == null) return;
                                Activity who = ctxObj instanceof Activity ? (Activity) ctxObj : null;
                                if (who == null) who = resolveByToken(token);
                                handle(who, it, rc, p);
                            }
                        });
                Logx.i("Instrumentation.execStartActivity hooked sig=" + java.util.Arrays.toString(pts));
            } catch (Throwable t) {
                Logx.w("hook execStartActivity failed sig=" + java.util.Arrays.toString(pts) + " : " + t);
            }
        }
    }

    /** 用 token 反查 Activity（兜底路径，拿不到就返回 null，不影响主路径） */
    private static Activity resolveByToken(Object binder) {
        if (binder == null) return null;
        try {
            Class<?> atc = Class.forName("android.app.ActivityThread");
            Object at = de.robv.android.xposed.XposedHelpers.callStaticMethod(atc, "currentActivityThread");
            if (at == null) return null;
            Object ar = de.robv.android.xposed.XposedHelpers.getObjectField(at, "mActivities");
            if (ar instanceof java.util.Map) {
                Object rec = ((java.util.Map) ar).get(binder);
                if (rec == null) return null;
                return (Activity) de.robv.android.xposed.XposedHelpers.getObjectField(rec, "activity");
            }
        } catch (Throwable t) { Logx.w("resolveByToken: " + t); }
        return null;
    }


    private static void handle(Activity caller, Intent it, int rc, MethodHookParam p) {
        if (it == null || p.returnEarly) return;
        if (INFLIGHT.get() == it) return;                 // 上层已处理，防止 FragmentActivity→Activity 双触发
        if (!SelectorSignature.isForwardSelector(it)) return;
        if (caller == null) { Logx.w("sig hit but caller null: " + SelectorSignature.desc(it)); return; }

        Logx.i("INTERCEPT(B) caller=" + caller.getClass().getName()
                + " rc=" + rc + " :: " + SelectorSignature.desc(it));

        INFLIGHT.set(it);
        try {
            OwnPickerController.attachOnCaller(caller, it, rc);
        } finally {
            INFLIGHT.remove();
        }
        p.setResult(null);      // 阻止原生选择器启动
    }
}
```

> `de.robv.android.xposed.XC_MethodHook.MethodHookParam` 中 `setResult()` 会置 `returnEarly=true`，**对 void 方法同样有效**（这是阻止原方法执行的标准姿势）。

### 4.12 `NativeMirror.java`（从原生列表扒同一份数据，best-effort）

> 这是**可选能力**。如果你自己的模块已经有联系人列表，把 §4.7 的 `source` 设成 `module` 即可，完全不需要这个类。
> 这里做"镜像"的好处是：选择器内容与微信原生完全一致（排序、索引、群/个人分类、已屏蔽账号）。

```java
package com.your.module.wxforward;

import android.app.Activity;
import android.view.View;
import android.view.ViewGroup;
import android.widget.AbsListView;

import java.lang.reflect.Field;
import java.lang.reflect.Method;
import java.util.ArrayList;
import java.util.Collection;
import java.util.LinkedHashSet;
import java.util.List;
import java.util.Set;

public final class NativeMirror {

    private static final String[] USER_KEYS = {"d", "username", "userName", "wxid", "user", "talker", "mUsername"};
    private static final String[] NICK_KEYS = {"F", "nickname", "nickName", "displayName", "remark", "mNickname"};
    private static final String[] LIST_KEYS = {"data", "mData", "E", "list", "items", "mList", "datas"};
    private static final String[] LIST_METHODS = {"getData", "getCurrentList", "getItems", "getMData"};
    private static final Set<String> EXCLUDE = new java.util.HashSet<>(java.util.Arrays.asList(
            "🔍", "☆", ""));

    private NativeMirror() {}

    /* ================= 对外 API ================= */

    /** 一次拿到宿主 Activity 里所有列表 Adapter（RecyclerView 与 AbsListView 都算） */
    public static List<Object> adaptersOf(Activity host) {
        List<Object> out = new ArrayList<>();
        if (host == null) return out;
        try {
            View content = host.findViewById(android.R.id.content);
            if (content instanceof ViewGroup) collectAdapters((ViewGroup) content, out, 0);
        } catch (Throwable t) { Logx.e("adaptersOf failed", t); }
        return out;
    }

    /** 某个 Adapter 的数据集（可能为 null） */
    public static Collection<?> dataOf(Object adapter) {
        if (adapter == null) return null;
        for (String m : LIST_METHODS) {
            try {
                Method mm = findMethod(adapter.getClass(), m);
                if (mm != null) {
                    mm.setAccessible(true);
                    Object r = mm.invoke(adapter);
                    if (r instanceof Collection) return (Collection<?>) r;
                }
            } catch (Throwable ignore) { }
        }
        for (String f : LIST_KEYS) {
            try {
                Field ff = findField(adapter.getClass(), f);
                if (ff != null) {
                    ff.setAccessible(true);
                    Object r = ff.get(adapter);
                    if (r instanceof Collection) return (Collection<?>) r;
                }
            } catch (Throwable ignore) { }
        }
        // 有些 Adapter 外面还包了一层 Holder
        for (Field f : adapter.getClass().getDeclaredFields()) {
            if (Collection.class.isAssignableFrom(f.getType())) continue;
            f.setAccessible(true);
            Object sub;
            try { sub = f.get(adapter); } catch (Throwable t) { continue; }
            if (sub == null) continue;
            for (String f2 : LIST_KEYS) {
                try {
                    Field ff = findField(sub.getClass(), f2);
                    if (ff != null) {
                        ff.setAccessible(true);
                        Object r = ff.get(sub);
                        if (r instanceof Collection) return (Collection<?>) r;
                    }
                } catch (Throwable ignore) { }
            }
        }
        return null;
    }

    /** 单个 Adapter 版本的 read()（供方案 D 换数据时用） */
    public static List<ContactItem> itemsOf(Object adapter) {
        List<ContactItem> out = new ArrayList<>();
        Collection<?> d = dataOf(adapter);
        if (d != null) for (Object o : d) {
            ContactItem c = toItem(o);
            if (c != null) out.add(c);
        }
        return out;
    }

    /** 从宿主 Activity 扒出全部联系人（按 username 去重） */
    public static List<ContactItem> read(Activity host) {
        Set<ContactItem> out = new LinkedHashSet<>();
        for (Object ad : adaptersOf(host)) {
            Collection<?> data = dataOf(ad);
            if (data == null) continue;
            for (Object item : data) {
                ContactItem c = toItem(item);
                if (c != null) out.add(c);
            }
        }
        Logx.i("mirror: adapters=" + adaptersOf(host).size() + " items=" + out.size());
        return new ArrayList<>(out);
    }

    /* ================= item 转换 ================= */

    private static ContactItem toItem(Object item) {
        if (item instanceof ContactItem) return (ContactItem) item;
        if (item instanceof String) {
            String s = (String) item;
            if (s.isEmpty() || EXCLUDE.contains(s)) return null;
            return new ContactItem(s, s, s.endsWith("@chatroom") ? 1 : 0);
        }
        String u = firstStringField(item, USER_KEYS);
        String n = firstStringField(item, NICK_KEYS);
        if (u == null || u.isEmpty()) u = heuristicUsername(item);
        if (u == null || u.isEmpty() || EXCLUDE.contains(u)) return null;
        if (n == null || n.isEmpty() || n.equals(u)) n = u;
        return new ContactItem(u, n, u.endsWith("@chatroom") ? 1 : 0);
    }

    /** 启发式：扫所有 String 字段，挑出"长得像 wxid"的那个 */
    private static String heuristicUsername(Object o) {
        for (Class<?> k = o.getClass(); k != null && !k.equals(Object.class); k = k.getSuperclass()) {
            for (Field f : k.getDeclaredFields()) {
                if (f.getType() != String.class) continue;
                f.setAccessible(true);
                String v;
                try { v = (String) f.get(o); } catch (Throwable t) { continue; }
                if (v == null || v.isEmpty() || EXCLUDE.contains(v)) continue;
                if (looksLikeWxid(v)) return v;
            }
        }
        return null;
    }

    public static boolean looksLikeWxid(String s) {
        if (s == null || s.length() < 4 || s.length() > 40) return false;
        if (s.indexOf(' ') >= 0) return false;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            boolean ok = (c >= 'a' && c <= 'z') || (c >= 'A' && c <= 'Z')
                    || (c >= '0' && c <= '9') || c == '_' || c == '-' || c == '@' || c == '.';
            if (!ok) return false;
        }
        return true;
    }

    /* ================= 视图/反射工具 ================= */

    private static void collectAdapters(ViewGroup g, List<Object> out, int depth) {
        if (g == null || depth > 12) return;
        if (isRecyclerView(g) || g instanceof AbsListView) {
            Object ad = callNoArg(g, "getAdapter");
            if (ad != null && !out.contains(ad)) out.add(ad);
            return;
        }
        for (int i = 0; i < g.getChildCount(); i++) {
            View c = g.getChildAt(i);
            if (c instanceof ViewGroup) collectAdapters((ViewGroup) c, out, depth + 1);
        }
    }

    public static boolean isRecyclerView(View v) {
        for (Class<?> k = v.getClass(); k != null; k = k.getSuperclass()) {
            String n = k.getSimpleName();
            if ("RecyclerView".equals(n) || "WxRecyclerView".equals(n)) return true;
        }
        return false;
    }

    private static String firstStringField(Object o, String[] keys) {
        for (String k : keys) {
            try {
                Field f = findField(o.getClass(), k);
                if (f != null) {
                    f.setAccessible(true);
                    Object v = f.get(o);
                    if (v instanceof String) return (String) v;
                }
            } catch (Throwable ignore) { }
        }
        return null;
    }

    private static Field findField(Class<?> c, String name) {
        for (Class<?> k = c; k != null && !k.equals(Object.class); k = k.getSuperclass()) {
            try { return k.getDeclaredField(name); } catch (NoSuchFieldException ignore) { }
        }
        return null;
    }

    private static Method findMethod(Class<?> c, String name) {
        for (Class<?> k = c; k != null && !k.equals(Object.class); k = k.getSuperclass()) {
            try { return k.getDeclaredMethod(name); } catch (NoSuchMethodException ignore) { }
        }
        return null;
    }

    public static Object callNoArg(Object o, String name) {
        Method m = findMethod(o.getClass(), name);
        if (m == null) return null;
        try { m.setAccessible(true); return m.invoke(o); } catch (Throwable t) { return null; }
    }
}
```

### 4.13 `NativeAdapterSwap.java`（方案 D：只换数据、保留原生 UI）

```java
package com.your.module.wxforward;

import android.app.Activity;

import java.util.Collection;
import java.util.List;

/**
 * 方案 D：不动 UI，只把原生 Adapter 的数据集替换成"过滤后的自有列表"。
 * 用 §4.12 的 mirror 拿到原始 item → 按 block_contact / 自有白名单过滤 → 整体换掉 data 字段并 notify。
 */
public final class NativeAdapterSwap {

    private NativeAdapterSwap() {}

    public static void apply(Activity host, android.content.Intent src) {
        if (host == null) return;
        for (Object ad : NativeMirror.adaptersOf(host)) {
            try {
                Collection<?> raw = NativeMirror.dataOf(ad);
                if (raw == null) continue;

                List<ContactItem> want = ContactSources.filter(src, NativeMirror.itemsOf(ad));
                if (want.isEmpty()) continue;

                @SuppressWarnings({"unchecked", "rawtypes"})
                Collection<Object> box = (Collection<Object>) raw;
                box.clear();
                box.addAll((Collection) want);

                NativeMirror.callNoArg(ad, "notifyDataSetChanged");
                Logx.i("adapter swapped " + ad.getClass().getName() + " -> " + want.size());
            } catch (Throwable t) {
                Logx.e("adapter swap failed for " + ad.getClass().getName(), t);
            }
        }
    }
}
```

### 5.1 指纹优先级（越靠前越不怕更新）

| 级别 | 指纹 | 样本实测 | 稳定性 |
|---|---|---|---|
| ★★★ | 日志字符串 `doCallSelectContactUI` | `SelectConversationUI.T7()` line 821 | 极高（微信极少改 Log 文案） |
| ★★★ | 日志字符串 `doCallSelectContactUIForMultiRetransmit` | `SelectConversationUI.U7()` line 866 | 极高 |
| ★★★ | 血缘锚点 `com.tencent.mm.plugin.mvvmlist.BaseMvvmListActivity` / `com.tencent.mm.ui.contact.MMBaseSelectContactUI` | 已用 `class_hierarchy` 验证 | 高 |
| ★★ | 结果契约 key `Select_Conv_User` / `Select_Contact` | 多处验证 | 极高 |
| ★★ | intent extras `list_type`/`titile`/`list_attr`/`block_contact`/`max_limit_num`/`already_select_contact` | T7/U7/b0.invoke | 高（ strings，不吃混淆） |

### 5.2 离线 DexKit 探针（新版本跑一次，产出类名清单）

```java
package com.your.module.probe;

import org.luckypray.dexkit.DexKitBridge;
import org.luckypray.dexkit.query.FindClass;
import org.luckypray.dexkit.query.FindMethod;
import org.luckypray.dexkit.query.matchers.ClassMatcher;
import org.luckypray.dexkit.query.matchers.MethodMatcher;
import org.luckypray.dexkit.result.ClassData;
import org.luckypray.dexkit.result.MethodData;

import java.io.File;
import java.io.FileWriter;
import java.util.ArrayList;
import java.util.HashSet;
import java.util.List;
import java.util.Set;

/**
 * 用法：probe <微信.apk 路径> <输出.txt 路径>
 * 产出一份 selector_classes.txt，把它写进模块的 Cfg.explicitClasses（或模块 files 目录）。
 *
 * 注意：DexKit 1.0.x / 1.1.x / 1.2.x / 2.x 的函数式接口名略有差异
 *      （FindClass / ClassMatcher / ClassData vs DexKitBridge.SearchEntity）；
 *      下面三段查询的"语义"不变，按你依赖的版本改成对应 API 即可。
 */
public final class VersionProbe {

    public static void main(String[] args) throws Exception {
        String apk = args[0];
        String out = args[1];
        Set<String> selectors = new HashSet<>();
        Set<String> pages = new HashSet<>();

        try (DexKitBridge bridge = DexKitBridge.create(apk, null, null)) {

            /* ---- 1) 转发页（按日志字符串） ---- */
            for (String log : new String[]{"doCallSelectContactUI", "doCallSelectContactUIForMultiRetransmit"}) {
                List<ClassData> cs = bridge.findClass(FindClass.create()
                        .matcher(ClassMatcher.create().usingStrings(log)));
                for (ClassData c : cs) { pages.add(c.getName()); }
                List<MethodData> ms = bridge.findMethod(FindMethod.create()
                        .matcher(MethodMatcher.create().usingStrings(log)));
                for (MethodData m : ms) {
                    pages.add(m.getClassName());
                    System.out.println("[LAUNCHER] " + m.getClassName() + "->" + m.getMethodSign());
                }
            }

            /* ---- 2) 联系人选择器（按血缘） ---- */
            for (String sup : new String[]{
                    "com.tencent.mm.plugin.mvvmlist.BaseMvvmListActivity",
                    "com.tencent.mm.ui.contact.MMBaseSelectContactUI"}) {
                List<ClassData> cs = bridge.findClass(FindClass.create()
                        .matcher(ClassMatcher.create().superClass(sup)));
                for (ClassData c : cs) selectors.add(c.getName());
            }

            /* ---- 3) 用契约字符串二次收敛 ---- */
            Set<String> byContract = new HashSet<>();
            for (String key : new String[]{"Select_Conv_User", "Select_Contact"}) {
                List<ClassData> cs = bridge.findClass(FindClass.create()
                        .matcher(ClassMatcher.create().usingStrings(key)));
                for (ClassData c : cs) byContract.add(c.getName());
            }
            selectors.retainAll(byContract.size() > 0 ? byContract : selectors);

            /* ---- 4) 血缘锚点本身也要记录（微信可能改名） ---- */
            Set<String> anchors = new HashSet<>();
            anchors.add("com.tencent.mm.plugin.mvvmlist.BaseMvvmListActivity");
            anchors.add("com.tencent.mm.ui.contact.MMBaseSelectContactUI");
            for (String log : new String[]{"MicroMsg.SelectConversationUI",
                                           "MicroMsg.MMBaseSelectContactUI",
                                           "MicroMsg.SelectContactUI"}) {
                for (ClassData c : bridge.findClass(FindClass.create()
                        .matcher(ClassMatcher.create().usingStrings(log)))) anchors.add(c.getName());
            }
        }

        FileWriter fw = new FileWriter(new File(out));
        fw.write("# generator: VersionProbe\n");
        fw.write("# FORWARD_PAGES\n");
        for (String s : pages) fw.write("P " + s + "\n");
        fw.write("# SELECTOR_CLASSES\n");
        for (String s : selectors) fw.write("S " + s + "\n");
        fw.write("# ANCHORS\n");
        for (String s : new HashSet<>(anchors)) fw.write("A " + s + "\n");
        fw.close();
        System.out.println("-> " + out + "  selectors=" + selectors.size());
    }
}
```

### 5.3 运行时自愈（不跑探针也能活）

即使探针没跑，`ParentChainInterceptor`（§4.10）已经在运行时自动识别：
1. 任何 `Activity` 只要 intent 命中转发指纹 **并且** 父类链里含血缘锚点 → 自动接管；
2. 血缘锚点列表 `ANCHORS` 也跟着探针产物更新（新版本换了基类时，探针会把新基类写进 `A ...` 行）；
3. 如果微信把血缘彻底换掉，退化成"仅 intent 指纹 + 显式类名"仍然可用（把 `Cfg.looseSignature` 打开 + `explicitClasses` 填上）。

### 5.4 微信更新后的 15 分钟适配流程

```
1. 打开 verboseTrace，跑一遍转发流程 → 看日志里 sig hit but chain miss: <类名>
       → 说明微信换了选择器基类；把该类名填进 explicitClasses，或把血缘锚点加进 ANCHORS
2. 日志里完全没有 sig hit
       → 说明 intent extras 契约变了；把日志里 reject(...) 的 intent dump 拿出来，
          按新 extras 改 SelectorSignature
3. 日志完全没有 INTERCEPT/HIT（连 onActivityResult 都没进来）
       → 说明结果契约变了；用 find_method(using_strings=["Select_Conv_User"]) 找新的 key
          （历史上还有 Select_Contact / scene_select_user_liast 等）
4. 日志有 HIT 但转发没发出去
       → 多半是 result extras 少了必填项；打开 passthroughExtras 再试
5. 全部跑完再关掉 verboseTrace
```

## 6. 风险清单 & 坑（务必过一遍）

| # | 风险 | 影响 | 规避 |
|---|---|---|---|
| 1 | `MvvmContactListUI` 是 `VASActivity`，**不能跳过 `super.onCreate`** | 状态机/ViewBinding 空指针 | 只用 `hookMethodAfter` + decor 覆盖，**不要** `param.setResult(null)` 跳过 super |
| 2 | 我们的 View 加在 decorView 上，微信 ActionBar 返回键被盖住 | 用户退不出去 | UI 自带返回按钮 + hook `onBackPressed`（§4.9） |
| 3 | 多进程 | `:push` / `:tools` 进程 hook 无 UI 只是浪费 | `HookEntry` 里按进程过滤（§4.1） |
| 4 | 混淆方法名 `T7`/`qs5.k4` | 更新即失效 | 本方案**完全不依赖**方法名 |
| 5 | `FragmentActivity`/`Activity` 的 `startActivityForResult` 可能被 override | hook 不触发 | 2 参/3 参 + Activity 版 + `Instrumentation.execStartActivity` 四路兜底 + `INFLIGHT` 去重 |
| 6 | `XSharedPreferences` 在新版 LSPosed 受限 | 配置读不到 | 退化为默认值；推荐改用 ContentProvider 或 files 目录 JSON（见 §9） |
| 7 | 弱网/大数据量下原生列表还没加载完 → `NativeMirror` 拿到空 | 选择器空白 | `onCreate` 后再延迟 1 帧刷新；或切 `source=module` |
| 8 | 选择器被其他业务复用（`AA`/`masssend`/`luckymoney` 等） | 误替换 | 严格签名（`list_type∈{5,14}` + 转发特征）+ 只用主进程 |
| 9 | 方案 B 伪造 `onActivityResult` | 极端时序下 fragment 未收到 | 默认关闭；真需要时优先用方案 A |
| 10 | 结果 extras 不够 → 转发静默失败 | 功能不可用 | **务必带 `Select_Conv_User`**；仍不行就开 `passthroughExtras` |
| 11 | 多选上限 | 超限后微信自己弹 toast | 读 intent `max_limit_num`（默认 9），UI 里提前拦住 |
| 12 | `Select_Conv_NextStep` 场景（带下一步的转发） | 走 `f8(intent, nextStep)` 分支 | 该分支只读 `Select_Conv_User`，已覆盖 |
| 13 | 企业微信分支 `Y7()` | 与本方案无关 | `Select_App_Id` 为空且 `l1` 为 true 才走，默认不受影响 |
| 14 | 微信主进程 hook 全局 `Activity#onCreate` | 性能 | 顺序：先 `isForwardSelector(intent)`（读 extras，纳秒级）→ 再走血缘链 |

### 9.1 LSPosed 新 API 入口（`io.github.libxposed.api`）

```java
package com.your.module;

import io.github.libxposed.api.XposedInterface;
import io.github.libxposed.api.XposedModule;
import io.github.libxposed.api.XposedModuleInterface;

public final class LsposedEntry extends XposedModule {

    public LsposedEntry(XposedInterface base, XposedModuleInterface.ModuleLoadedParam param) {
        super(base, param);
    }

    @Override
    public void onPackageLoaded(XposedModuleInterface.PackageLoadedParam param) {
        if (!param.isFirstPackage) return;
        if (!"com.tencent.mm".equals(param.getPackageName())) return;
        if (!Cfg.isUiProcess(param.getProcessName())) return;
        XposedInterface.Hooker hooker = new XposedInterface.Hooker() {
            @Override public void before(XposedInterface.MethodHookParam<?> p) {
                android.content.Intent it = (android.content.Intent) p.getArgs()[0];
                if (!SelectorSignature.isForwardSelector(it)) return;
                p.returnAndSkip(null);
                OwnPickerController.attachOnCaller(
                        (android.app.Activity) p.getThisObject(), it, (Integer) p.getArgs()[1]);
            }
            @Override public void after(XposedInterface.MethodHookParam<?> p) { }
        };
        try {
            hook(Class.forName("androidx.fragment.app.FragmentActivity", false, param.getClassLoader())
                    .getMethod("startActivityForResult", android.content.Intent.class, int.class), hooker.getPriority(), hooker);
        } catch (Throwable t) { t.printStackTrace(); }
    }
}
```

### 9.2 关于 `Select_Conv_NextStep` 的补充

`T7` 的结果若命中"带下一步"的场景，微信会 `f8(intent, nextStep)`，该分支只读 `Select_Conv_User`：

2. `Cfg.MODULE_PKG` 改成你的模块包名；
3. `HookEntry` 写进 `assets/xposed_init`（classic 模块）或按 §9.1 改成 `XposedModule`；
4. 装微信 + 你的模块，进设置页把 `verboseTrace` 打开、`mode=0`、`source=mirror`；
5. 聊天页长按消息 → 转发 → 点左下角入口 → 看 LSPilot/Xposed 日志里的 `HIT ... list_type=5 ...`；
6. 选择器出现 = 替换成功；选人 → 发送成功 = 契约打通；
7. 关掉 `verboseTrace`，收工。

**如果 5 分钟没成**

按 §5.4 的 5 步排查；日志里出现 `sig hit but chain miss: <类名>` 时，把类名填进 `explicitClasses` 即可（那是微信换了选择器基类，属于唯一需要动手的场景）。
