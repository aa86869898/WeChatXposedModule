三、语音消息(type=34)相关字段 ★★★
================================================================================

  核心字段:
  field_content    — 语音XML: 包含 duration(时长), format(格式), voiceUrl等
  field_lvbuffer   — 语音二进制数据(AMR/SILK格式)
  field_imgPath    — 语音文件本地路径: /voice2/<md5>.amr
  field_reserved   — 语音元数据(可能是格式/采样率等)

  获取方法:
  I0() → String           获取 content (语音XML)
  j() → String            获取 content 别名
  Q0() → String           可能是 imgPath
  R0() → String           可能是 reserved
  P0() → String           可能是另一个字符串
  N0() → String           可能是 talker

  时间相关:
  getCreateTime() → long  语音发送/接收时间 (未混淆, 可直接用)
  H0() → long             获取 msgId (getMsgId混淆名)

  状态相关:
  O0() → int              status (可能包含语音播放状态)
  G1() → boolean          isSend (是否自己发送)
  isVideo() → boolean     是否视频

  语音文件路径结构:
  数据库: /data/user/0/com.tencent.mm/MicroMsg/<hash>/voice2/<md5>.amr
  文件名可从 field_content 的 XML 中解析, 或通过 ExtVoiceMsgIdToFileNameEvent

六、关键发现 — isSend 确认
================================================================================

  ✅ convertFrom 第367-372行确认:
     "if (contentValues.containsKey("isSend")) {
          this.field_isSend = contentValues.getAsInteger("isSend").intValue();
      }"
  
  → field_isSend 字段确实存在! 是在 dm.c8 父类中, 不在 storage.e9 自身。
  
  但是日志中 isSend=53/13774 的原因是:
    你旧模块的 MessageHook 尝试用 XposedHelpers.getIntField() 读取,
    但传入的是 storage.e9 对象, 而 field_isSend 在父类 dm.c8 中,
    由于混淆, 字段的真实Java名不是 "field_isSend" 而是某个混淆名(可能是A或B等).
  
  ✅ 正确读取方式:
    方法1: 遍历父类字段用 getDeclaredFields()
    方法2: 用 G1() 方法 (已经确认返回boolean)
    方法3: 从父类 dm.c8 读取: 
           Object parent = msgInfo;  // 本身就是 dm.c8 子类
           遍历 parent.getClass().getSuperclass().getDeclaredFields()


七、语音消息 XML 结构 (field_content 内容)
================================================================================

  语音消息 type=34 时 content 格式:
    <msg>
      <voicemsg endflag="1" 
                cancelflag="0"
                length="5000"           ← 时长(毫秒)
                voiceformat="4"          ← 格式(4=AMR)
                voicelength="5000"
                forwardflag="0"
                bufid="..."             ← 文件标识
                fromusername="wxid_xxx"
                clientmsgid="..." />
    </msg>

  或简单格式: wxid_xxx:0:0  (群聊中可能是 sender:0:0)
