## 1. 功能概述

群聊/私聊中收到含群二维码的图片时，自动识别二维码、判断是否群邀请、自动加入群聊。全程后台执行，无需手动操作。非群二维码不触发。

**特性：**
- 不依赖任何第三方库
- 复用微信内置 QR 识别引擎
- 精准过滤群邀请 vs 普通 QR 码
- 已处理消息去重

## 2. 核心链路

```
┌─────────────────────────────────────────────────────┐
│  消息到达 → MessageHook 检测 type=3（图片）          │
│    │                                                │
│    ├─ e9.y0() 获取图片文件路径                       │
│    ├─ new File(path).exists() 校验文件存在            │
│    │                                                │
│    ├─ 构造 RecogQBarOfImageFileEvent                 │
│    │   ├─ g.b = imgPath（图片路径）                  │
│    │   ├─ g.d = null（扫描全部码类型）                │
│    │   └─ event.e() 发布 → 微信 QR 引擎异步识别      │
│    │                                                │
│    └─ 监听 IEvent.e() 拦截 RecogQBarOfImageFileResult│
│        │                                            │
│        ├─ g.b = ArrayList<String>（二维码内容列表）   │
│        ├─ 遍历 → isGroupInvite(url)                  │
│        │   └─ url 含 "weixin.qq.com/g/" → 群邀请     │
│        │                                            │
│        └─ CreateOrJoinChatroomEvent 加群             │
│            ├─ g.a = 1                                │
│            ├─ g.b = new String[]{url}                │
│            └─ event.e()                              │
└─────────────────────────────────────────────────────┘
```

## 3. 微信内部机制分析

### 3.1 QR 码识别引擎

微信使用 `RecogQBarOfImageFileEvent` 触发图片 QR 识别，引擎异步执行后发布 `RecogQBarOfImageFileResultEvent`。

| 类 | 包路径 | 作用 |
|----|--------|------|
| `RecogQBarOfImageFileEvent` | `com.tencent.mm.autogen.events` | QR识别请求 |
| `RecogQBarOfImageFileResultEvent` | `com.tencent.mm.autogen.events` | QR识别结果 |
| `ImageQBarDataBean` | `com.tencent.mm.plugin.scanner` | 单个QR码数据 |

**RecogQBarOfImageFileEvent 结构：**
```
g: am.bq
  ├─ a: long          → msgId
  ├─ b: String        → 图片文件路径 ★
  ├─ c: Bitmap        → 可为null（引擎自己加载）
  ├─ d: Set           → 扫描类型（null=全部）
  ├─ e: boolean       → 
  ├─ f: int           → 
  ├─ g: boolean       → 
  ├─ h: String        → 
  ├─ i: ScanCodeInfo  → 
  └─ j: int           → 
```

**RecogQBarOfImageFileResultEvent 结构：**
```
g: am.dq
  ├─ a: String           → 原图路径
  ├─ b: ArrayList<String> → ★ 二维码文本列表
  ├─ c: ArrayList<String> → 码类型列表
  ├─ d..j, m: ArrayList  → 其他分类结果
  ├─ k: int
  ├─ l: boolean
  └─ n: uz3/l
```

### 3.2 QR 码类型分类（来自 GestureGalleryUI.c7 + z0 类）

微信内部将 QR 码分为三类：

| e 字段值 | 常量名 | 含义 | z0 方法 | 示例 |
|---------|--------|------|---------|------|
| 22 (0x16) | WX_CODE | 微信码 | `z0.o()` | 群邀请码、小程序码 |
| 19 (0x13) | — | 其他微信码 | `z0.l()`, `z0.d()`, `z0.g()` | 公众号、支付码 |
| 其他 | QR_CODE | 普通码 | — | 任意URL/文本 |

**关键代码（GestureGalleryUI.c7）：**
```java
h0Var.g = imageQBarDataBean.e == 22 ? "WX_CODE" : "QR_CODE";
h0Var.f = imageQBarDataBean.d;  // 二维码URL
```

### 3.3 群邀请 URL 特征（来自 z0.<clinit>）

```java
// z0.b 静态字段 — 群邀请URL模板
"http://"  + weixinHost + "/g/"   →  "http://weixin.qq.com/g/XXXXX"
"https://" + weixinHost + "/g/"   →  "https://weixin.qq.com/g/XXXXX"
```

**判断群邀请：**
```java
url.contains("/g/") && url.contains("weixin.qq.com")
```

### 3.4 图片路径获取

`e9.y0()` 方法对 type=3 图片消息通过 `o2.qj().h()` 查询图片存储表返回文件路径。文件可能未下载，需 `new File(path).exists()` 校验。

### 3.5 加群机制

`CreateOrJoinChatroomEvent` — 微信内部创建/加入群聊事件：
```
g: am.q3
  ├─ a: int          → 操作类型（1=加入）
  ├─ b: String[]     → URL数组
  ├─ c: String[]     → 
  └─ d: Context      → 可为null
```

## 4. 完整代码

### AutoJoinGroup.java

```java
package com.leshao.v3;

import de.robv.android.xposed.*;
import de.robv.android.xposed.callbacks.XC_LoadPackage;
import java.io.File;
import java.util.*;

/**
 * 自动扫码进群
 * 
 * 【原理】
 *   1. MessageHook 检测 type=3（图片）消息
 *   2. e9.y0() 获取图片文件路径
 *   3. RecogQBarOfImageFileEvent 触发微信 QR 识别引擎
 *   4. IEvent.e() 拦截 RecogQBarOfImageFileResultEvent 获取结果
 *   5. 过滤 isGroupInvite(url) → URL 含 /g/ 模式
 *   6. CreateOrJoinChatroomEvent 自动加群
 *
 * 【集成】
 *   MainHook.activateAll() 中加: AutoJoinGroup.hook(lpparam);
 *   MessageHook type==3 时加:  AutoJoinGroup.onImageMsg(e9);
 */
public class AutoJoinGroup {

    private static final String TAG = "AutoJoinGroup";
    private static final Set<Long> processed = Collections.synchronizedSet(new HashSet<>());

    // ================================================================
    // 入口：注册 hook
    // ================================================================
    public static void hook(XC_LoadPackage.LoadPackageParam lp) {
        ClassLoader cl = lp.classLoader;
        try {
            Class<?> iEventClz = cl.loadClass("com.tencent.mm.sdk.event.IEvent");
            Class<?> resultEvtClz = cl.loadClass(
                "com.tencent.mm.autogen.events.RecogQBarOfImageFileResultEvent");

            XposedHelpers.findAndHookMethod(iEventClz, "e", new XC_MethodHook() {
                @Override
                protected void beforeHookedMethod(MethodHookParam p) {
                    if (resultEvtClz.isInstance(p.thisObject)) {
                        onQrResult(p.thisObject);
                    }
                }
            });
            Log.e(TAG, "QR结果监听已挂载 — AutoJoinGroup 就绪");
        } catch (Throwable e) {
            Log.e(TAG, "hook失败: " + e.getMessage(), e);
        }
    }

    // ================================================================
    // 图片消息到达时调用（在 MessageHook 的 type==3 分支）
    // ================================================================
    public static void onImageMsg(Object e9) {
        try {
            long msgId = (Long) XposedHelpers.callMethod(e9, "getMsgId");
            if (processed.contains(msgId)) return;

            String path = (String) XposedHelpers.callMethod(e9, "y0");
            String talker = (String) XposedHelpers.callMethod(e9, "N0");
            Log.e(TAG, "图片到达: msgId=" + msgId + " talker=" + talker);
            Log.e(TAG, "  路径: " + path);

            if (path == null || path.isEmpty()) {
                Log.e(TAG, "  路径为空, 跳过");
                return;
            }
            File f = new File(path);
            if (!f.exists()) {
                Log.e(TAG, "  文件不存在(" + f.length() + "b), 跳过");
                return;
            }
            Log.e(TAG, "  文件OK: " + f.length() + " bytes");

            processed.add(msgId);
            triggerQr(msgId, path, e9.getClass().getClassLoader());

        } catch (Throwable e) {
            Log.e(TAG, "onImageMsg异常: " + e.getMessage(), e);
        }
    }

    // ================================================================
    // 触发微信 QR 识别引擎
    // ================================================================
    private static void triggerQr(long msgId, String imgPath, ClassLoader cl) {
        try {
            Class<?> evtClz = cl.loadClass(
                "com.tencent.mm.autogen.events.RecogQBarOfImageFileEvent");

            Object event = XposedHelpers.newInstance(evtClz);
            Object g = XposedHelpers.getObjectField(event, "g");  // am.bq

            XposedHelpers.setLongField(g, "a", msgId);
            XposedHelpers.setObjectField(g, "b", imgPath);
            // c(Bitmap) = null → 微信自己加载
            // d(Set)    = null → 扫描全部类型
            XposedHelpers.setBooleanField(g, "e", false);
            XposedHelpers.setIntField(g, "f", 0);
            XposedHelpers.setBooleanField(g, "g", false);
            XposedHelpers.setObjectField(g, "h", "");
            XposedHelpers.setIntField(g, "j", 0);

            XposedHelpers.callMethod(event, "e");  // publish
            Log.e(TAG, "QR识别已触发: msgId=" + msgId);

        } catch (Throwable e) {
            Log.e(TAG, "QR触发失败: " + e.getMessage());
        }
    }

    // ================================================================
    // QR 识别结果回调
    // ================================================================
    private static void onQrResult(Object event) {
        try {
            Object g = XposedHelpers.getObjectField(event, "g");  // am.dq
            String imgPath = (String) XposedHelpers.getObjectField(g, "a");
            @SuppressWarnings("unchecked")
            ArrayList<String> texts = (ArrayList<String>) XposedHelpers.getObjectField(g, "b");

            if (texts == null || texts.isEmpty()) {
                Log.e(TAG, "QR结果为空: " + imgPath);
                return;
            }

            Log.e(TAG, "=== QR识别到 " + texts.size() + " 个码 ===");
            for (int i = 0; i < texts.size(); i++) {
                String url = texts.get(i);
                Log.e(TAG, "  [" + i + "] " + url);

                if (isGroupInvite(url)) {
                    Log.e(TAG, "  ★★★ 检测到群邀请！★★★");
                    joinGroup(url, event.getClass().getClassLoader());
                    return;
                }
            }
            Log.e(TAG, "  未匹配群邀请");
        } catch (Throwable e) {
            Log.e(TAG, "onQrResult异常: " + e.getMessage());
        }
    }

    // ================================================================
    // 群邀请判断
    // 来源: plugin.scanner.z0.<clinit>
    //   z0.b = ["http://host/g/", "https://host/g/"]
    // ================================================================
    private static boolean isGroupInvite(String url) {
        if (url == null) return false;
        return url.contains("/g/") && url.contains("weixin.qq.com");
    }

    // ================================================================
    // 加群
    // ================================================================
    private static void joinGroup(String url, ClassLoader cl) {
        try {
            Log.e(TAG, "→ 尝试加群: " + url);

            Class<?> evtClz = cl.loadClass(
                "com.tencent.mm.autogen.events.CreateOrJoinChatroomEvent");
            Object event = XposedHelpers.newInstance(evtClz);
            Object g = XposedHelpers.getObjectField(event, "g");  // am.q3

            XposedHelpers.setIntField(g, "a", 1);
            XposedHelpers.setObjectField(g, "b", new String[]{url});
            XposedHelpers.setObjectField(g, "c", null);
            XposedHelpers.setObjectField(g, "d", null);

            boolean ok = (Boolean) XposedHelpers.callMethod(event, "e");
            Log.e(TAG, "加群事件发送: " + ok);

        } catch (Throwable e) {
            Log.e(TAG, "加群失败: " + e.getMessage());
        }
    }
}
```

## 6. 调试指南

### 6.1 关键日志

| 日志 | 含义 | 排查方向 |
|------|------|---------|
| `QR结果监听已挂载` | Hook成功 | — |
| `图片到达: msgId=...` | 检测到图片 | — |
| `路径为空, 跳过` | e9.y0() 无返回 | 图片未下载完成 |
| `文件不存在` | 文件路径无效 | 检查路径格式 |
| `QR识别已触发` | 事件发布成功 | — |
| `QR结果为空` | 未识别到码 | 图片不含QR码 |
| `检测到群邀请` | 命中群URL | — |
| `加群事件发送` | 加群请求已发 | — |

### 6.2 测试步骤

1. 部署模块后重启微信
2. 找一个人发一张**群二维码图片**到聊天
3. 查看日志输出：
   - `图片到达` → 确认检测到
   - `QR识别已触发` → 确认触发
   - `QR识别到 N 个码` → 确认识别
   - `检测到群邀请` → 确认过滤
   - `加群事件发送` → 确认加群

### 6.3 验证 URL 模式

如果群邀请 URL 格式变了，修改 `isGroupInvite()` 方法：

```java
private static boolean isGroupInvite(String url) {
    if (url == null) return false;
    // 打印所有 URL 来找新模式
    Log.e(TAG, "URL: " + url);
    // 当前模式
    return url.contains("/g/") && url.contains("weixin.qq.com");
}
```

## 7. 常见问题

### Q: 收到图片但没触发
A: 检查 `e9.getType()` 返回值。群聊图片可能是 type=3 或 type=47（大图）。在 `onImageMsg` 里加日志看实际 type 值。

### Q: 文件不存在
A: 图片可能还在下载中。可以加延时重试：
```java
new Handler(Looper.getMainLooper()).postDelayed(() -> {
    if (new File(path).exists()) {
        triggerQr(msgId, path, cl);
    }
}, 3000);
```

### Q: QR 识别触发了但没有结果
A: 可能 `RecogQBarOfImageFileEvent` 的参数不对。尝试设置 `g.d` 为指定类型集合。

### Q: 加群失败
A: `CreateOrJoinChatroomEvent` 可能需要 Context。尝试传入当前 Activity：
```java
XposedHelpers.setObjectField(g, "d", getCurrentActivity());
```

### Q: 同一个图片重复触发
A: 代码已用 `processed` Set 做去重，按 msgId 过滤。如果需要更持久化的去重，可改用 SharedPreferences。
